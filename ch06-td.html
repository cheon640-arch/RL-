part 1from mc to td

Limitation of MC RL MC의 한계

p.2 – 4

복습: MC는 에피소드 경험에서 직접 배우고, model-free이며, 완전한 에피소드로 배우고(부트스트래핑 없음), 가치 = 평균 리턴.

복습: Episodic task(끝이 있음) vs Continuous task(끝이 없음, \(\gamma \ne 1\); 예: 로봇 청소기, 주식 트레이딩, 공장 제어, 신호 제어).

limitation
  • MC RL은 continuous task에 적용하기 어렵다 (에피소드가 안 끝나니 리턴을 못 구함).
  • 에피소드가 길면 학습이 느리고 불안정하다.

DP

모든 가능한 다음 상태 1스텝 (모델 필요, 부트스트래핑 O)

MC

샘플 한 경로를 끝까지 (모델 불필요, 부트스트래핑 X)

TD

샘플 한 경로를 1스텝만 (모델 불필요, 부트스트래핑 O) → DP와 MC의 장점을 합침!

DP, MC, TD 세 가지 업데이트 식

p.5
업데이트
DP\(V_{\pi}'(s) = \sum_{a,s'} \pi(a\mid s)\,p(s'\mid s,a)\big[r(s,a,s') + \gamma V_\pi(s')\big]\)
MC\(V_\pi'(S_t) = V_\pi(S_t) + \alpha\big[G_t - V_\pi(S_t)\big]\)
TD\(V_\pi'(S_t) = V_\pi(S_t) + \alpha\big[R_{t+1} + \gamma V_\pi(S_{t+1}) - V_\pi(S_t)\big]\)

TD는 어디서 왔을까? 벨만 기대 방정식을 기댓값 꼴로 쓰면:

\[v_\pi(s) = \sum_{a,s'}\pi(a\mid s)\,p(s'\mid s,a)\big[r(s,a,s') + \gamma v_\pi(s')\big] = \E_\pi\big[R_{t+1} + \gamma v_\pi(S_{t+1}) \mid S_t = s\big]\]

기댓값을 모르니까 샘플 하나 \(R_{t+1} + \gamma V(S_{t+1})\)로 대신하고, MC처럼 조금씩(α) 그쪽으로 옮기는 것!

\[V_\pi'(S_t) = V_\pi(S_t) + \alpha\big[\underbrace{\overbrace{R_{t+1} + \gamma V_\pi(S_{t+1})}^{\text{TD target}} - V_\pi(S_t)}_{\text{TD error } (\delta_t)}\big]\]

MC vs TD 장단점

p.8
  • TD는 최종 결과를 알기 전에 학습할 수 있다
    • TD는 매 스텝 후 온라인으로 학습 가능
    • MC는 에피소드가 끝나 리턴이 알려질 때까지 기다려야 함
  • TD는 최종 결과 없이도 학습할 수 있다
    • TD는 불완전한 수열로부터 학습 가능, MC는 완전한 수열로부터만
    • TD는 연속(종료 없는) 환경에서도 작동, MC는 에피소드(종료) 환경에서만

Bias/Variance Trade-Off 편향과 분산

p.9 – 10
  • 리턴 \(G_t = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{T-1}R_T\)는 \(v_\pi(S_t)\)의 불편(unbiased) 추정치
  • 진짜 TD 타깃 \(R_{t+1} + \gamma v_\pi(S_{t+1})\)도 \(v_\pi(S_t)\)의 불편 추정치
  • 하지만 실제 TD 타깃 \(R_{t+1} + \gamma V(S_{t+1})\)은 편향된(biased) 추정치 — 부트스트래핑(추정치 \(V\)를 쓰니까)
  • TD 타깃은 리턴보다 분산이 훨씬 작다:
    • 리턴은 많은 무작위 행동·전이·보상에 의존
    • TD 타깃은 무작위 행동·전이·보상 하나에만 의존

MC: 높은 분산, 편향 0

  • 수렴 성질이 좋다
  • 초기값에 그다지 민감하지 않다
  • 이해하고 쓰기 매우 간단

TD: 낮은 분산, 약간의 편향

  • 보통 MC보다 효율적
  • TD(0)는 \(v_\pi(s)\)로 수렴
  • 초기값에 더 민감

\(V(B)\): B에서 8번 중 6번 보상 1 → 둘 다 \(V(B) = 6/8 = 0.75\).

part 2sarsa

Updating Action-Value Functions with SARSA

p.16 – 17

TD를 \(V\)에서 \(Q\)로 바꾸면 (MC 때처럼 model-free 제어를 하려고):

\[V_\pi'(S_t) = V_\pi(S_t) + \alpha\big[R_{t+1} + \gamma V_\pi(S_{t+1}) - V_\pi(S_t)\big]\]
\[Q_\pi'(S_t, A_t) = Q_\pi(S_t,A_t) + \alpha\big[R_{t+1} + \gamma Q_\pi(S_{t+1}, A_{t+1}) - Q_\pi(S_t,A_t)\big]\]

업데이트에 \((S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1})\) 다섯 개가 쓰여서 이름이 S-A-R-S-A!

\[\begin{aligned} Q(S_t,A_t) &\leftarrow Q(S_t,A_t) + \alpha\big[R_{t+1} + \gamma Q(S_{t+1},A_{t+1}) - Q(S_t,A_t)\big] \\ &= (1-\alpha)\, Q(S_t,A_t) + \alpha\big[R_{t+1} + \gamma Q(S_{t+1},A_{t+1})\big] \end{aligned}\]
  • 두 항의 가중합
  • \(\alpha\): 학습률(learning rate) / 스텝 크기(step size)
    • \(\alpha = 0\): 아무것도 배우지 않음
    • \(\alpha = 1\): 가장 최근 정보만 고려

SARSA vs Monte Carlo Control

p.18

SARSA

  • 매 타임스텝마다
  • 평가: TD, \(Q \approx q_\pi\)
  • 개선: ε-greedy 정책 개선

Monte Carlo Control

  • 매 에피소드마다
  • 평가: MC 정책 평가, \(Q \approx q_\pi\)
  • 개선: ε-greedy 정책 개선
# SARSA (on-policy TD control)
Q = defaultdict(lambda: 0)
for episode in range(N):
    S = env.reset();  A = eps_greedy(Q, S)
    while not done:
        S2, R, done = env.step(A)
        A2 = eps_greedy(Q, S2)                        # 다음 행동을 실제로 먼저 고르고
        target = R if done else R + gamma * Q[S2, A2]   # 그 행동의 Q 로 타깃
        Q[S, A] += alpha * (target - Q[S, A])
        S, A = S2, A2                                  # 고른 A2 를 그대로 실행

Convergence of SARSA

p.19
theorem

SARSA는 다음 조건에서 최적 행동가치함수로 수렴한다, \(Q(s,a) \to q_*(s,a)\):

  • 정책 수열 \(\pi_t(a\mid s)\)가 GLIE
  • 스텝 크기 \(\alpha_t\)가 Robbins-Monro 수열:
    \[\sum_{t=1}^{\infty} \alpha_t = \infty, \qquad \sum_{t=1}^{\infty} \alpha_t^2 \lt \infty\]
Robbins-Monro 직관첫째 조건: 스텝 합이 무한 → 초기값이 아무리 멀어도 도달할 수 있을 만큼 충분히 움직임. 둘째 조건: 스텝이 충분히 빨리 작아짐 → 노이즈가 결국 사라져 한 점에 수렴. 예: \(\alpha_t = 1/t\) ✓, 상수 α ✗(둘째 조건 위반).

part 3q-learning

Q-Learning

p.27 – 28

SARSA ← 벨만 기대 방정식

\[q_\pi(s,a) = \sum_{s'} p(s'\mid s,a)\Big[r + \gamma \sum_{a'} \pi(a'\mid s') q_\pi(s',a')\Big]\]
\[Q(s,a) \leftarrow Q(s,a) + \alpha\big[R + \gamma Q(s',a') - Q(s,a)\big]\]

Q-learning ← 벨만 최적 방정식

\[q_*(s,a) = \sum_{s'} p(s'\mid s,a)\Big[r + \gamma \max_{a'} q_*(s',a')\Big]\]
\[Q(s,a) \leftarrow Q(s,a) + \alpha\big[R + \gamma \max_{a'} Q(s',a') - Q(s,a)\big]\]

DP에서 “정책 평가 ↔ 가치 이터레이션”이 기대/최적 방정식에서 나왔듯, 샘플링 버전은 “SARSA ↔ Q-learning”.

Target Policy & Behavior Policy

p.30 – 31

Target Policy (타깃 정책)

  • 에이전트가 배우려는 정책
  • 에이전트는 이 정책의 가치함수를 학습

Behavior Policy (행동 정책)

  • 에이전트가 실제로 행동을 고르고 샘플을 생성하는 데 쓰는 정책

SARSA의 타깃 \(R + \gamma Q(s',a')\)에서 \(a'\)는 ε-greedy로 뽑은 행동 → 타깃 정책 = ε-greedy. Q-learning의 타깃 \(R + \gamma \max_{a'}Q(s',a')\) → 타깃 정책 = 그리디.

SARSA vs Q-Learning 같은 샘플, 다른 업데이트

p.32

위 3×3 예제에서 4번째 샘플 이후 Q: \(Q(1,D) = Q(4,D) = Q(7,R) = -0.1\), 나머지 0. 이제 5번째 샘플이 S=1, A=D, R=−1, S′=4, A′=D라면:

SARSA

\[\begin{aligned} Q(1,D) &\leftarrow -0.1 + 0.1\big[-1 + 0.9\,Q(4,D) - (-0.1)\big] \\ &= -0.1 + 0.1[-1 - 0.09 + 0.1] = -0.199 \end{aligned}\]

실제로 고른 A′=D의 Q(4,D)=−0.1 사용

Q-learning

\[\begin{aligned} Q(1,D) &\leftarrow -0.1 + 0.1\big[-1 + 0.9\max_a Q(4,a) - (-0.1)\big] \\ &= -0.1 + 0.1[-1 + 0 + 0.1] = -0.19 \end{aligned}\]

상태 4에서 가장 좋은 Q 값(0, 아직 안 가 본 행동) 사용

Convergence of Q-Learning

p.33
theorem

Q-learning은 다음 조건에서 최적 행동가치함수로 수렴한다, \(Q(s,a) \to q_*(s,a)\):

  • (행동) 정책 수열 \(\pi_t(a\mid s)\)가 GLIE
  • 스텝 크기가 Robbins-Monro: \(\sum_t \alpha_t = \infty,\ \sum_t \alpha_t^2 \lt \infty\)

On-Policy vs Off-Policy

p.34 – 35

On-Policy (SARSA)

  • Target policy = Behavior policy
  • \(Q(s,a)\) 업데이트 시 타깃 \(R + \gamma Q(s',a')\)는 행동 정책(ε-greedy)으로 \(s'\)에서 고른 \(a'\)를 사용
  • 업데이트 후, 에이전트는 (그 \(a'\)를 그대로) 행동 정책으로 \(s'\)에서 행동

장점: 학습 과정이 안정적
단점: 샘플 비효율, 느린 수렴

Off-Policy (Q-learning)

  • Target policy ≠ Behavior policy
  • \(Q(s,a)\) 업데이트 시 타깃 \(R + \gamma \max_a Q(s',a)\)는 \(Q(s',a)\)를 최대화하는 \(a\)를 사용
  • 업데이트 후, 에이전트는 행동 정책(ε-greedy)으로 \(s'\)에서 새로 행동을 고름

장점: 샘플 효율적, 빠른 수렴
단점: 학습 과정이 불안정

On-Policy vs Off-Policy: Cliff Walking

p.36 – 39

START에서 GOAL까지 가는 가장 좋은 방법은?

  • State: 위치 (4×12 격자), Action: 상하좌우
  • Cliff: 맨 아래 줄에서 Start와 Goal 사이의 칸들
  • Reward: 절벽에 빠지면 −100 (그리고 Start로 돌아감), 그 외 모든 전이 −1

도전 과제: 떨어질 위험 / 안전성과 최적성 사이의 트레이드오프

Q-learning (Off-policy)

  • 최적 정책에 집중, 목표까지 스텝 수를 최소화하려 함
  • 위험이 더 크더라도 절벽 바로 옆의 최단 경로를 학습할 가능성이 높음

SARSA (On-policy)

  • 현재 정책에 집중, 탐험 행동까지 학습에 반영
  • 절벽 근처에서 위험한 탐험으로 인한 큰 페널티를 피해, 절벽에서 먼 안전한 경로를 학습할 가능성이 높음

part 4extension of td

n-Step TD

p.41 – 42

TD 타깃이 \(n\)스텝 미래까지 보게 하자! (TD = 1-step, MC = ∞-step)

\[\begin{aligned} n=1\ \text{(TD)}: &\quad G_t^{(1)} = R_{t+1} + \gamma V(S_{t+1}) \\ n=2: &\quad G_t^{(2)} = R_{t+1} + \gamma R_{t+2} + \gamma^2 V(S_{t+2}) \\ &\quad\vdots \\ n=\infty\ \text{(MC)}: &\quad G_t^{(\infty)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{T-1} R_T \end{aligned}\]
definition · n-step return
\[G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1}R_{t+n} + \gamma^n V(S_{t+n})\]

n-step TD learning:

\[V(S_t) \leftarrow V(S_t) + \alpha\big(G_t^{(n)} - V(S_t)\big)\]

Averaging n-Step Returns

p.43
  • 서로 다른 \(n\)의 n-step 리턴을 평균 낼 수 있다.
  • Complex backup: 더 단순한 백업들을 평균한 백업. 예) 2-step과 4-step 리턴의 평균 \(\tfrac12 G^{(2)} + \tfrac12 G^{(4)}\)
  • 모든 타임스텝의 정보를 효율적으로 합칠 수는 없을까? → TD(λ)

TD(λ) λ-return, forward view

p.44

\(\lambda\)-리턴 \(G_t^\lambda\)는 모든 n-step 리턴 \(G_t^{(n)}\)을 가중치 \((1-\lambda)\lambda^{n-1}\)로 합친 것 (\(0 \le \lambda \le 1\)):

\[G_t^\lambda = (1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1} G_t^{(n)} = (1-\lambda)\sum_{n=1}^{T-t-1}\lambda^{n-1}G_t^{(n)} + \lambda^{T-t-1}G_t\]

(에피소드가 \(T\)에서 끝나면 \(n \ge T-t\)인 모든 n-step 리턴이 실제 리턴 \(G_t\)와 같아서 그 가중치들이 \(\lambda^{T-t-1}\)로 모임.)

Forward-view TD(λ):

\[V(S_t) \leftarrow V(S_t) + \alpha\big(\underbrace{G_t^\lambda - V(S_t)}_{\lambda\text{-error}}\big)\]

\(\text{TD}(0) = \text{TD}\), \(\text{TD}(1) = \text{MC}\)

근데 문제가…Forward view는 \(G_t^\lambda\)를 계산하려면 결국 미래를 다 봐야 해서 MC처럼 에피소드 끝까지 기다려야 해요 → backward view로 해결!

Backward View of TD(λ): Episodic Task

p.45

TD 오차: \(\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\). λ-오차를 펼쳐서 정리하면

\[\begin{aligned} G_t^\lambda - V(S_t) = -V(S_t) &+ (1-\lambda)\lambda^0\,[R_{t+1} + \gamma V(S_{t+1})] \\ &+ (1-\lambda)\lambda^1\,[R_{t+1} + \gamma R_{t+2} + \gamma^2 V(S_{t+2})] \\ &+ (1-\lambda)\lambda^2\,[R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \gamma^3 V(S_{t+3})] + \cdots \\ &+ \lambda^{T-t-1}\,[R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{T-t-1}R_T] \end{aligned}\]

보상 \(R_{t+k}\)끼리, \(V(S_{t+k})\)끼리 모으면 (\(R_{t+k}\)의 계수는 \((\gamma\lambda)^{k-1}\), \(V(S_{t+k})\)는 \(+(\gamma\lambda)^{k-1}\gamma\)와 \(-(\gamma\lambda)^{k}\) 두 번 나옴):

\[\begin{aligned} &= (\gamma\lambda)^0\,[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)] \\ &\quad+ (\gamma\lambda)^1\,[R_{t+2} + \gamma V(S_{t+2}) - V(S_{t+1})] \\ &\quad+ \cdots + (\gamma\lambda)^{T-t-1}\,[R_T + \gamma V(S_T) - V(S_{T-1})] \\ &= \delta_t + (\gamma\lambda)\delta_{t+1} + (\gamma\lambda)^2\delta_{t+2} + \cdots + (\gamma\lambda)^{T-t-1}\delta_{T-1} \\ &= \sum_{k=t}^{T-1}(\gamma\lambda)^{k-t}\delta_k = \sum_{k=t}^{T}(\gamma\lambda)^{k-t}\delta_k \quad (\delta_T = 0) \end{aligned}\]
key result

λ-오차 = 앞으로 나올 TD 오차들의 \((\gamma\lambda)\)-할인 합. 즉 미래 대신 매 스텝 나오는 TD 오차 \(\delta_k\)를 과거 상태들에 나눠 주면 같은 결과!

Backward View of TD(λ): Continuous Task

p.46

종료가 없는 경우도 똑같이 무한히 펼쳐서 정리하면:

\[G_t^\lambda - V(S_t) = \delta_t + (\gamma\lambda)\delta_{t+1} + (\gamma\lambda)^2\delta_{t+2} + \cdots = \sum_{k=t}^{\infty}(\gamma\lambda)^{k-t}\delta_k\]

Eligibility Trace 적격 흔적

p.47

각 상태가 지금 나온 TD 오차에 대해 “얼마나 책임이 있는지”를 기록하는 값 \(E_t(s) \in \R^+\).

  • 초기값은 0: \(E_0(s) = 0,\ \forall s \in \S\)
  • 매 스텝, 방문하지 않은 모든 상태의 trace는 \(\gamma\lambda\)배로 감쇠: \(E_t(s) = \gamma\lambda E_{t-1}(s),\ \forall s \ne S_t\)
  • 시각 \(t\)에 방문한 상태 \(S_t\)의 trace: \(E_t(S_t) = \gamma\lambda E_{t-1}(S_t) + 1\)
  • \(\lambda\): trace-decay parameter

한 줄로: \(E_t(s) = \gamma\lambda E_{t-1}(s) + \mathbf{1}(S_t = s)\). 그리고 backward TD(λ)는 매 스텝 모든 상태를

\[V(s) \leftarrow V(s) + \alpha\,\delta_t\,E_t(s), \quad \forall s\]

로 업데이트해요. 최근에 자주 방문한 상태일수록 큰 몫을 받아요 (빈도 + 최근성 휴리스틱).

Forwards and Backwards TD(λ) 둘은 같다

p.48

상태 \(s\)가 에피소드 중 시각 \(k\)에 한 번 방문되었다고 하면, trace는 방문 이후 시간을 할인해요:

\[E_t(s) = \gamma\lambda E_{t-1}(s) + \mathbf{1}(S_t = s) = \begin{cases} 0 & \text{if } t \lt k \\ (\gamma\lambda)^{t-k} & \text{if } t \ge k \end{cases}\]

Backward TD(λ)의 업데이트를 에피소드 동안 누적하면:

\[\sum_{t=1}^{T}\alpha\,\delta_t\,E_t(s) = \alpha\sum_{t=k}^{T}(\gamma\lambda)^{t-k}\delta_t = \alpha\big(G_k^\lambda - V(S_k)\big)\]
  • 에피소드가 끝날 때 backward view는 λ-리턴의 총 오차를 정확히 누적한다 → forward view와 동일!
  • 같은 상태 \(s\)를 여러 번 방문하면 \(E_t(s)\)가 여러 오차를 누적한다 (accumulating trace).
    • Replacing eligibility trace: \(E_t(s) = \mathbf{1}(S_t = s)\) 처럼 방문 시 1로 리셋하는 변형

SARSA(λ) and Watkins’s Q(λ)

p.49 – 50 
# SARSA(λ)
init Q(s,a) arbitrarily
repeat (each episode):
  E(s,a) = 0  for all s,a
  init S, A
  repeat (each step):
    take A, observe R, S'
    choose A' from S' (ε-greedy on Q)
    δ ← R + γQ(S',A') − Q(S,A)
    E(S,A) ← E(S,A) + 1        # accumulating
    #  or (1−α)E(S,A) + 1       dutch
    #  or 1                    replacing
    for all s, a:
      Q(s,a) ← Q(s,a) + αδE(s,a)
      E(s,a) ← γλE(s,a)
    S ← S'; A ← A'
  until S is terminal
# Watkins's Q(λ)
init Q(s,a) arbitrarily
repeat (each episode):
  E(s,a) = 0  for all s,a
  init S, A
  repeat (each step):
    take A, observe R, S'
    choose A' from S' (ε-greedy on Q)
    A* ← argmax_a Q(S',a)
         (A' 가 동점이면 A* ← A')
    δ ← R + γQ(S',A*) − Q(S,A)
    E(S,A) ← E(S,A) + 1   (or dutch/replacing)
    for all s, a:
      Q(s,a) ← Q(s,a) + αδE(s,a)
      if A' = A*: E(s,a) ← γλE(s,a)
      else:       E(s,a) ← 0     # 탐험하면 trace 끊기
    S ← S'; A ← A'
  until S is terminal
Watkins Q(λ)의 포인트Q-learning의 타깃 정책은 그리디. 그래서 행동 정책이 그리디가 아닌 탐험 행동(A′ ≠ A*)을 하면, 그 뒤의 경험은 타깃 정책의 경험이 아니므로 trace를 0으로 끊어요.

Self-check 스스로 확인하기

TD target과 TD error를 식으로 쓰면?
TD target: \(R_{t+1} + \gamma V(S_{t+1})\). TD error: \(\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\).
MC는 편향 0·높은 분산, TD는 약간의 편향·낮은 분산인 이유는?
MC의 \(G_t\)는 실제 리턴이라 불편이지만 많은 무작위 사건의 합이라 분산이 큼. TD 타깃은 추정치 \(V(S_{t+1})\)를 써서(부트스트래핑) 편향이 생기지만 무작위 사건 하나에만 의존해 분산이 작음.
AB 예제에서 batch MC와 batch TD의 V(A)는?
MC: 0 (관측된 리턴 평균), TD: 0.75 (추정 MDP에서 A→B, V(B)=0.75).
SARSA와 Q-learning의 타깃 차이 한 줄 요약?
SARSA: 실제로 고른 다음 행동의 \(Q(S',A')\). Q-learning: 다음 상태의 최대 \(\max_a Q(S',a)\).
Cliff Walking에서 Q-learning이 학습 중 평균 보상이 더 낮은 이유는?
절벽 바로 옆 최단 경로(최적)를 학습하지만 실제 행동은 ε-greedy라 가끔 탐험하다 절벽에 떨어져 −100을 받음. SARSA는 탐험까지 고려해 안전한 경로를 택함.
Robbins-Monro 조건은? 상수 α는 만족하나요?
\(\sum \alpha_t = \infty\), \(\sum \alpha_t^2 \lt \infty\). 상수 α는 \(\sum\alpha^2 = \infty\)라 두 번째 조건을 만족하지 않음.
TD(0)와 TD(1)은 각각 무엇과 같나요?
TD(0) = 1-step TD, TD(1) = MC.
Eligibility trace 업데이트 식은?
\(E_0(s)=0\), \(E_t(s) = \gamma\lambda E_{t-1}(s) + \mathbf{1}(S_t=s)\). 그리고 \(V(s) \leftarrow V(s) + \alpha\delta_t E_t(s)\).
