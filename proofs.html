lecture 02MDP

Returns 리턴

02장 원래 위치 → p.18
definition

리턴 \(G_t\)는 시점 \(t\)부터의 할인된 보상의 총합이다.

\[G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}\]
  • 할인율 \(\gamma \in [0,1]\)은 미래 보상의 현재 가치.
  • \(k+1\) 스텝 뒤에 받는 보상 \(R\)의 가치는 \(\gamma^k R\).
  • 즉, 지연된 보상보다 즉각적인 보상을 더 높게 평가한다.
    • \(\gamma\)가 0에 가까우면 “근시안적(myopic)” 평가
    • \(\gamma\)가 1에 가까우면 “원시안적(far-sighted)” 평가

Value Function 가치함수

02장 원래 위치 → p.25
definition · state-value

MDP의 상태가치함수 \(v_\pi(s)\): 상태 \(s\)에서 시작해서 정책 \(\pi\)를 따를 때의 기대 리턴

\[v_\pi(s) = \E_\pi[G_t \mid S_t = s]\]
definition · action-value

행동가치함수 \(q_\pi(s,a)\): 상태 \(s\)에서 행동 \(a\)를 하고, 그 뒤로 정책 \(\pi\)를 따를 때의 기대 리턴

\[q_\pi(s,a) = \E_\pi[G_t \mid S_t = s, A_t = a]\]

둘의 관계 — 상태가치는 행동가치를 정책 확률로 평균낸 것:

\[v_\pi(s) = \sum_{a \in \A(s)} \pi(a \mid s)\, q_\pi(s,a), \quad \forall s \in \S\]

Optimal Value Function 최적 가치함수

02장 원래 위치 → p.27
definition

최적 상태가치함수 \(v_*(s)\)는 모든 정책에 대한 가치함수의 최댓값

\[v_*(s) = \max_\pi v_\pi(s)\]
definition

최적 행동가치함수 \(q_*(s,a)\)는 모든 정책에 대한 행동가치함수의 최댓값

\[q_*(s,a) = \max_\pi q_\pi(s,a)\]

최적 가치함수는 MDP에서 낼 수 있는 “최선의 성능”을 나타내고, 이걸 알면 MDP는 “풀렸다(solved)”고 할 수 있어요.

Optimal Policy 최적 정책

02장 원래 위치 → p.28

정책들 사이에 부분 순서(partial ordering)를 정의:

\[\pi \ge \pi' \quad \text{if} \quad v_\pi(s) \ge v_{\pi'}(s),\ \forall s\]
theorem

모든 MDP에 대해

  • 다른 모든 정책보다 좋거나 같은 최적 정책 \(\pi_*\)가 존재한다: \(\pi_* \ge \pi,\ \forall \pi\)
  • 모든 최적 정책은 최적 가치함수를 달성한다: \(v_{\pi_*}(s) = v_*(s)\)
  • 모든 최적 정책은 최적 행동가치함수를 달성한다: \(q_{\pi_*}(s,a) = q_*(s,a)\)

즉, 최적 정책 \(\pi_*\)는

\[v_{\pi_*}(s) \ge v_\pi(s),\ \forall s \in \S \qquad q_{\pi_*}(s,a) \ge q_\pi(s,a),\ \forall s \in \S, a \in \A\]
왜 “부분” 순서?정책 A가 어떤 상태에선 낫고 다른 상태에선 못할 수 있어서, 모든 정책 쌍이 비교 가능한 건 아니에요. 그래도 “모든 상태에서 최고”인 정책은 항상 존재한다는 게 이 정리의 핵심!

lecture 03Bellman

Bellman Expectation Equation: v 상태가치함수

03장 원래 위치 → p.4

Step 1. 리턴의 재귀 구조

\[G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = R_{t+1} + \gamma (R_{t+2} + \gamma R_{t+3} + \cdots) = R_{t+1} + \gamma G_{t+1}\]

Step 2. 기댓값 취하기

\[\begin{aligned} v_\pi(s) &= \E_\pi[G_t \mid S_t = s] = \E_\pi[R_{t+1} + \gamma G_{t+1} \mid S_t = s] \\ &= \E_\pi[R_{t+1} \mid S_t = s] + \gamma\, \E_\pi[G_{t+1} \mid S_t = s] \end{aligned}\]

Step 3. 첫째 항 (즉각 보상)

\[\E_\pi[R_{t+1} \mid S_t = s] = \sum_a \sum_{s'} \pi(a \mid s)\, p(s' \mid s,a)\, r(s,a,s')\]

Step 4. 둘째 항 (미래 리턴) — 5단계 유도

\[\begin{aligned} \E_\pi[G_{t+1} \mid S_t = s] &= \sum_a \sum_{s'} \E_\pi[G_{t+1} \mid S_{t+1}=s', s, a]\; p(S_{t+1}=s', a \mid s) && (1)\to(2) \\ &= \sum_a \sum_{s'} \E_\pi[G_{t+1} \mid S_{t+1}=s', s, a]\; \pi(a\mid s)\, p(s' \mid s,a) && (2)\to(3) \\ &= \sum_a \sum_{s'} \E_\pi[G_{t+1} \mid S_{t+1}=s']\; \pi(a\mid s)\, p(s' \mid s,a) && (3)\to(4) \\ &= \sum_a \sum_{s'} \pi(a\mid s)\, p(s' \mid s,a)\, v_\pi(s') && (4)\to(5) \end{aligned}\]
  • (1)→(2): 전확률 기댓값 법칙 (law of total expectation)
  • (2)→(3): 연쇄 법칙 (조건부 확률의 chain rule): \(p(s', a \mid s) = \pi(a\mid s)\,p(s'\mid s,a)\)
  • (3)→(4): 마르코프 성질 — \(S_{t+1}\)을 알면 \(s, a\)는 더 이상 필요 없음
  • (4)→(5): 가치함수의 정의
bellman expectation eq. (v)
\[v_\pi(s) = \sum_a \sum_{s'} \pi(a \mid s)\, p(s' \mid s,a) \big[ r(s,a,s') + \gamma v_\pi(s') \big]\]
읽는 법“정책으로 행동을 고르고(π), 환경이 다음 상태를 정하면(p), 그때 받는 보상 + 할인된 다음 가치”의 평균.

Matrix Form 행렬로 쓰기

03장 원래 위치 → p.5 – 6

MDP 복습: \(\P^{a}_{ss'} = P[S_{t+1}=s' \mid S_t=s, A_t=a]\), \(\Rc^{a}_{s} = \E[R_{t+1} \mid S_t=s, A_t=a]\). 정책 \(\pi\)로 평균을 내면 MRP처럼 쓸 수 있어요:

\[\P^{\pi}_{ss'} = \sum_{a \in \A} \pi(a\mid s)\, \P^{a}_{ss'}, \qquad \Rc^{\pi}_{s} = \sum_{a \in \A} \pi(a\mid s)\, \Rc^{a}_{s}\]
\[\begin{aligned} v_\pi(s) &= \sum_a \sum_{s'} \pi(a\mid s) p(s'\mid s,a)\big[r(s,a,s') + \gamma v_\pi(s')\big] \\ &= \sum_a \pi(a\mid s) \sum_{s'} p(s'\mid s,a) r(s,a,s') + \gamma \sum_{s'} v_\pi(s') \sum_a \pi(a\mid s) p(s'\mid s,a) \\ &= \sum_{a} \pi(a\mid s) \Rc^{a}_{s} + \gamma \sum_{s'} v_\pi(s')\, \P^{\pi}_{ss'} \\ &= \Rc^{\pi}_{s} + \gamma \sum_{s'} \P^{\pi}_{ss'}\, v_\pi(s') \end{aligned}\]

모든 상태 \(1, \dots, n\)에 대해 쌓으면:

\[\begin{bmatrix} v_\pi(1) \\ \vdots \\ v_\pi(n) \end{bmatrix} = \begin{bmatrix} \Rc^\pi_1 \\ \vdots \\ \Rc^\pi_n \end{bmatrix} + \gamma \begin{bmatrix} \P^\pi_{11} & \cdots & \P^\pi_{1n} \\ \vdots & \ddots & \vdots \\ \P^\pi_{n1} & \cdots & \P^\pi_{nn} \end{bmatrix} \begin{bmatrix} v_\pi(1) \\ \vdots \\ v_\pi(n) \end{bmatrix}\]
closed form
\[v_\pi = \Rc^\pi + \gamma \P^\pi v_\pi \;\;\Longrightarrow\;\; v_\pi = (I - \gamma \P^\pi)^{-1} \Rc^\pi\]
하지만!역행렬 계산은 \(O(n^3)\) — 상태가 많으면 불가능. 그래서 4장(DP)의 반복법이 필요해요.

Bellman Expectation Equation: q 행동가치함수

03장 원래 위치 → p.7 – 8

복습: \(v_\pi(s) = \E_\pi[G_t\mid S_t=s]\), \(q_\pi(s,a) = \E_\pi[G_t\mid S_t=s, A_t=a]\), \(v_\pi(s) = \sum_{a} \pi(a\mid s) q_\pi(s,a)\).

\[\begin{aligned} q_\pi(s,a) &= \E_\pi[G_t \mid S_t=s, A_t=a] = \E_\pi[R_{t+1} + \gamma G_{t+1} \mid S_t=s, A_t=a] \\ &= \E_\pi[R_{t+1} \mid s, a] + \gamma\, \E_\pi[G_{t+1} \mid s, a] \\ &= \sum_{s'} p(s'\mid s,a)\big[ r(s,a,s') + \gamma v_\pi(s') \big] \\ &= \sum_{s'} p(s'\mid s,a)\Big[ r(s,a,s') + \gamma \sum_{a' \in \A(s')} \pi(a'\mid s')\, q_\pi(s',a') \Big] \end{aligned}\]

여기서 \(\E_\pi[R_{t+1}\mid s,a] = \sum_{s'} p(s'\mid s,a) r(s,a,s')\), \(\E_\pi[G_{t+1}\mid s,a] = \sum_{s'} p(s'\mid s,a)\,\E_\pi[G_{t+1}\mid S_{t+1}=s'] = \sum_{s'} p(s'\mid s,a)\, v_\pi(s')\).

bellman expectation eq. (q)
\[q_\pi(s,a) = \sum_{s'} p(s' \mid s,a) \Big[ r(s,a,s') + \gamma \sum_{a' \in \A(s')} \pi(a' \mid s')\, q_\pi(s',a') \Big]\]
v 와 다른 점q는 행동 \(a\)가 이미 정해져 있으니 첫 단계엔 π가 없고, 다음 상태에서 π로 다음 행동 \(a'\)를 고른다!

\(v_*(s) = \max_a q_*(s,a)\) 왜 성립할까

03장 원래 위치 → p.11 – 12

복습: 최적 정책 \(\pi_*\)는 존재하고, \(v_{\pi_*} = v_*\), \(q_{\pi_*} = q_*\) (2장 p.28).

theorem

어떤 \(s^* \in \S\), \(a^* \in \A(s^*)\)에 대해 \(q_\pi(s^*, a^*) \ge v_\pi(s^*)\) 이면, 정책

\[\pi'(a\mid s) = \pi(a \mid s)\,(1 - \delta_{s,s^*}) + \delta_{s,s^*}\,\delta_{a,a^*}\]

에 대해 \(v_{\pi'}(s) \ge v_\pi(s),\ \forall s \in \S\). 여기서 \(\delta_{ij} = 1\ (i=j),\ 0\ (i \ne j)\) (Kronecker delta).

즉, “\(s^*\)에서만 행동을 \(a^*\)로 바꾸고 나머지는 그대로 둔 정책 \(\pi'\)”은 원래보다 나쁘지 않아요.

proof

임의의 \(s \in \S\)에 대해

\[\begin{aligned} v_\pi(s) &= \E_{\pi}[q_\pi(s, A_t) \mid S_t = s] \\ &\le \E_{\pi'}[q_\pi(s, A_t) \mid S_t = s] \\ &= \E_{\pi'}[R_{t+1} + \gamma v_\pi(S_{t+1}) \mid S_t = s] \\ &\le \E_{\pi'}[R_{t+1} + \gamma\, \E_{\pi'}[q_\pi(S_{t+1}, A_{t+1}) \mid S_{t+1}] \mid S_t = s] \\ &= \E_{\pi'}[R_{t+1} + \gamma\, \E_{\pi'}[R_{t+2} + \gamma v_\pi(S_{t+2}) \mid S_{t+1}, A_{t+1}] \mid S_t = s] \\ &= \E_{\pi'}[R_{t+1} + \gamma R_{t+2} + \gamma^2 v_\pi(S_{t+2}) \mid S_t = s] \\ &\le \E_{\pi'}[R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots \mid S_t = s] = v_{\pi'}(s). \quad \blacksquare \end{aligned}\]

부등호(≤)는 매번 “\(s^*\)에 도착했을 때 \(\pi\) 대신 \(a^*\)를 고르면 \(q_\pi(s^*,a^*) \ge v_\pi(s^*)\)라서 손해가 없다”는 사실을 쓴 것. 이걸 한 스텝씩 계속 펼친 거예요.

그래서 결론최적 정책에서 \(q_*(s,a) \gt v_*(s)\)인 행동이 있다면 더 좋은 정책을 만들 수 있으니 모순. 따라서 최적에선 가장 좋은 행동의 가치가 곧 상태의 가치: \[v_*(s) = \max_a q_*(s,a)\]

Bellman Optimality Equation: v* 최적 상태가치

03장 원래 위치 → p.13
\[\begin{aligned} v_*(s) &= \max_{a \in \A(s)} q_{\pi_*}(s,a) \\ &= \max_{a} \E_{\pi_*}[G_t \mid S_t=s, A_t=a] \\ &= \max_{a} \E_{\pi_*}[R_{t+1} + \gamma G_{t+1} \mid S_t=s, A_t=a] \\ &= \max_{a} \E[R_{t+1} + \gamma v_*(S_{t+1}) \mid S_t=s, A_t=a] \\ &= \max_{a} \sum_{s'} p(s'\mid s,a)\big[r(s,a,s') + \gamma v_*(s')\big] \end{aligned}\]
bellman optimality eq. (v*)
\[v_*(s) = \max_{a \in \A(s)} \sum_{s'} p(s' \mid s,a)\big[r(s,a,s') + \gamma v_*(s')\big]\]

전이가 결정적이면 합이 사라져서 \(v_*(s) = \max_{a} \big[r(s,a,s') + \gamma v_*(s')\big]\).

기대 방정식과 비교정책 확률로 평균 \(\sum_a \pi(a\mid s)\) 내던 자리가 \(\max_a\)로 바뀌었어요. max는 비선형이라 역행렬로 한 번에 못 풀어요!

Bellman Optimality Equation: q* 최적 행동가치

03장 원래 위치 → p.14
\[\begin{aligned} q_*(s,a) &= \E_{\pi_*}[G_t \mid S_t=s, A_t=a] = \E_{\pi_*}[R_{t+1} + \gamma G_{t+1} \mid S_t=s, A_t=a] \\ &= \E_{\pi_*}[R_{t+1} \mid s, a] + \gamma\,\E_{\pi_*}[G_{t+1} \mid s, a] \\ &= \sum_{s'} p(s'\mid s,a)\big[r(s,a,s') + \gamma v_*(s')\big] \\ &= \sum_{s'} p(s'\mid s,a)\Big[r(s,a,s') + \gamma \max_{a' \in \A(s')} q_*(s',a')\Big] \end{aligned}\]
bellman optimality eq. (q*)
\[q_*(s,a) = \sum_{s'} p(s' \mid s,a)\Big[r(s,a,s') + \gamma \max_{a' \in \A(s')} q_*(s',a')\Big]\]
중요!이 식이 6장 Q-learning의 출발점이에요. 그리고 q*만 알면 최적 정책은 \(\pi_*(s) = \argmax_a q_*(s,a)\)로 바로 나옴 — 모델(p)이 필요 없음!

Metric Space 거리 공간

03장 원래 위치 → p.18 – 20

“최적 가치함수가 정말 존재하고 하나뿐일까?”에 답하려면 수학 도구가 몇 개 필요해요. (참고: medium “Why does the optimal policy exist?”)

definition

거리 공간은 순서쌍 \((M, d)\)로, 집합 \(M\)과 거리함수(metric) \(d(x,y)\)로 이루어지며 모든 \(x,y,z \in M\)에 대해:

  • \(d(x,y) \ge 0\) — 비음수성
  • \(d(x,y) = 0 \Leftrightarrow x = y\) — 식별 불가능자의 동일성
  • \(d(x,y) = d(y,x)\) — 대칭성
  • \(d(x,z) \le d(x,y) + d(y,z)\) — 삼각부등식

\(\R^n\)에서의 거리 예시 (\(x=(x_1..x_n), y=(y_1..y_n)\))

  • 맨해튼 거리 (\(L_1\)): \(d(x,y) = |x_1 - y_1| + \cdots + |x_n - y_n|\)
  • 유클리드 거리 (\(L_2\)): \(d(x,y) = \sqrt{(x_1-y_1)^2 + \cdots + (x_n-y_n)^2}\)
  • 체비셰프 거리 (\(L_\infty\)): \(d(x,y) = \max\{|x_1-y_1|, \dots, |x_n-y_n|\}\) ← 앞으로 이걸 씀!

Cauchy Sequence & Complete Metric Space 코시 수열, 완비공간

03장 원래 위치 → p.21 – 22
definition · cauchy

거리 공간 \((M,d)\)의 수열 \(x_1, x_2, \dots\)가 코시라는 것은, 모든 \(\varepsilon \gt 0\)에 대해 어떤 양의 정수 \(N\)이 있어서 모든 \(m, n \gt N\)에 대해 \(d(x_m, x_n) \lt \varepsilon\).

직관: 뒤로 갈수록 항들끼리 서로 한없이 가까워지는 수열.

definition · complete

\((M,d)\)의 모든 코시 수열이 \(M\) 안에서 수렴하면(극한이 \(M\)에 있으면) \((M,d)\)를 완비(complete)라고 한다.

  • 예1. 유리수 \(\mathbb{Q}\) (절댓값 거리)는 완비가 아니다. \(x_1 = 1,\ x_{n+1} = \dfrac{x_n}{2} + \dfrac{1}{x_n}\) 은 모든 항이 유리수인 코시 수열이지만 \(\sqrt{2} \notin \mathbb{Q}\)로 수렴.
  • 예2. 실수 \(\R\), 복소수 \(\mathbb{C}\), 유클리드 공간 \(\R^n\)은 완비다. → 가치함수 벡터가 사는 \(\R^{|\S|}\)도 완비!

Contraction Mapping 축약사상

03장 원래 위치 → p.23
definition

\((M,d)\)가 거리 공간일 때, 사상 \(T: M \to M\)이 축약사상이라는 것은 어떤 \(0 \le \gamma \lt 1\)이 있어서

\[d(T(x), T(y)) \le \gamma\, d(x,y), \quad \forall x, y \in M\]

직관: \(T\)를 적용할 때마다 두 점 사이 거리가 최소 \(\gamma\)배로 줄어든다 → 반복하면 \(d_n \le \gamma^n d_0 \to 0\).

예. \(\R^1\), \(d(x,y) = |x-y|\)에서 \(T(x) = x/2\): \(d(T(x),T(y)) = |x/2 - y/2| = \tfrac12 |x-y| = \tfrac12 d(x,y)\). → \(\gamma = 1/2\)인 축약사상.

Banach Fixed-Point Theorem 바나흐 고정점 정리

03장 원래 위치 → p.24
theorem

\((M,d)\)가 공집합이 아닌 완비 거리 공간이고 \(T: M \to M\)이 축약사상이면, \(T\)는 \(M\) 안에 유일한 고정점 \(x^*\)를 가진다 (즉 \(T(x^*) = x^*\)).

또한 임의의 \(x_0 \in M\)에서 시작해 \(x_n = T(x_{n-1})\ (n \ge 1)\)로 수열을 만들면 \(\lim_{n\to\infty} x_n = x^*\).

왜 중요?“존재” + “유일” + “아무 데서 시작해도 반복하면 찾아감” 세 가지를 한 번에 보장! 4장의 정책 평가·가치 이터레이션이 수렴하는 근거가 바로 이것.

The Bellman Optimality Operator \(T\)

03장 원래 위치 → p.25
  • 가치함수 벡터: \(v = [v(s) : s \in \S] \in \R^{|\S|}\)
  • 벨만 최적 방정식: \(v_*(s) = \max_{a} \sum_{s'} p(s'\mid s,a)[r(s,a,s') + \gamma v_*(s')]\)
  • 벨만 최적 연산자 \(T: \R^{|\S|} \to \R^{|\S|}\):
    \[(Tv)(s) = \max_{a \in \A(s)} \E\big[R_{t+1} + \gamma v(S_{t+1}) \mid S_t = s, A_t = a\big]\]
  • 그러면 벨만 최적 방정식은 \(v_* = T v_*\) — 즉 \(v_*\)는 \(T\)의 고정점!

A Property of the Max Operator 보조정리

03장 원래 위치 → p.26
lemma

유한집합 \(A\)와 두 함수 \(f_1, f_2: A \to \R\)에 대해

\[\Big|\max_{a\in A} f_1(a) - \max_{a\in A} f_2(a)\Big| \le \max_{a \in A} |f_1(a) - f_2(a)|\]
proof

i) \(a_1\)을 \(f_1(a_1) = \max_a f_1(a)\)인 점이라 하면

\[\max_a f_1(a) - \max_a f_2(a) = f_1(a_1) - \max_a f_2(a) \le f_1(a_1) - f_2(a_1) \le \max_a\big(f_1(a) - f_2(a)\big) \le \max_a |f_1(a) - f_2(a)|\]

ii) 같은 방법으로 \(f_2(a_2) = \max_a f_2(a)\)인 \(a_2\)를 잡으면 \(\max_a f_2(a) - \max_a f_1(a) \le \max_a |f_1(a) - f_2(a)|\).

두 부등식을 합치면 절댓값 부등식 성립. \(\blacksquare\)

Existence and Uniqueness of Optimal Value Function

03장 원래 위치 → p.27
theorem

거리 공간 \((\R^{|\S|}, \|\cdot\|_\infty)\) 위에서 벨만 최적 연산자 \(T\)는 축약사상이다. 즉

\[\|Tv - Tv'\|_\infty \le \gamma\, \|v - v'\|_\infty, \quad \forall v, v' \in \R^{|\S|}\]
proof
\[\begin{aligned} \|Tv - Tv'\|_\infty &= \max_{s} |Tv(s) - Tv'(s)| \\ &= \max_s \Big| \max_a \E[R_{t+1} + \gamma v(S_{t+1}) \mid s,a] - \max_a \E[R_{t+1} + \gamma v'(S_{t+1}) \mid s,a] \Big| \\ &\le \max_s \max_a \Big| \E[R_{t+1} + \gamma v(S_{t+1}) \mid s,a] - \E[R_{t+1} + \gamma v'(S_{t+1}) \mid s,a] \Big| && \text{(보조정리)} \\ &= \max_s \max_a \gamma\, \big|\E[v(S_{t+1}) - v'(S_{t+1}) \mid s,a]\big| && (R \text{ 상쇄}) \\ &\le \max_s \max_a \gamma\, \E\big[|v(S_{t+1}) - v'(S_{t+1})| \mid s,a\big] \\ &\le \max_s \max_a \gamma\, \E\big[\|v - v'\|_\infty \mid s,a\big] \\ &= \gamma\, \|v - v'\|_\infty. \quad \blacksquare \end{aligned}\]

따라서 \(T\)는 \(\gamma\)-축약사상이고, \(\R^{|\S|}\)는 완비이므로 바나흐 고정점 정리에 의해:

  • \(v_* = Tv_*\)를 만족하는 \(v_*\)가 존재하고 유일하다.
  • 아무 \(V_0\)에서 시작해 \(V_{k+1} = TV_k\)를 반복하면 \(v_*\)로 수렴한다 → 4장 가치 이터레이션!

Bellman Expectation Operator is Contraction Mapping

04장 원래 위치 → p.6 – 7
theorem

\((\R^{|\S|}, \|\cdot\|_\infty)\)에서 벨만 기대 연산자 \(T^\pi: \R^{|\S|}\to\R^{|\S|}\)는 축약사상이다:

\[\|T^\pi v - T^\pi v'\|_\infty \le \gamma\, \|v - v'\|_\infty, \quad \forall v, v'\]
proof
\[\begin{aligned} |T^\pi v(s) - T^\pi v'(s)| &= \big|\E_\pi[R_{t+1} + \gamma v(S_{t+1}) \mid s] - \E_\pi[R_{t+1} + \gamma v'(S_{t+1}) \mid s]\big| \\ &= \big|\gamma\, \E_\pi[v(S_{t+1}) - v'(S_{t+1}) \mid s]\big| \\ &\le \gamma\, \E_\pi\big[|v(S_{t+1}) - v'(S_{t+1})| \mid s\big] \\ &\le \gamma\, \E_\pi\big[\|v - v'\|_\infty \mid s\big] = \gamma\, \|v - v'\|_\infty \end{aligned}\]

모든 \(s\)에 대해 성립하므로 \(\|T^\pi v - T^\pi v'\|_\infty \le \gamma \|v - v'\|_\infty\). 즉 \(T^\pi\)는 \(\gamma\)-축약사상. \(\blacksquare\)

(3장의 최적 연산자 증명과 달리 max가 없어서 보조정리 없이 바로 됨!)

바나흐 고정점 정리 다시 소환완비 공간 + 축약사상 ⇒ 유일한 고정점이 존재하고 반복하면 수렴. 벨만 기대 방정식은 고정점 \(v_\pi\)를 정의하므로, \(V_k = T^\pi V_{k-1}\)을 반복하면 \(\lim_{k\to\infty} V_k = v_\pi\).

Policy Improvement Theorem 정책 개선 정리

04장 원래 위치 → p.30
theorem

\(\pi\)와 \(\pi'\)가 임의의 정책 쌍일 때 (슬라이드 필기: “deterministic” 삭제 → 확률적 정책에도 성립),

\[q_\pi(s, \pi'(s)) \ge v_\pi(s) = \sum_a \pi(a\mid s)\, q_\pi(s,a)\quad \forall s \in \S \;\;\Longrightarrow\;\; v_{\pi'}(s) \ge v_\pi(s)\quad \forall s \in \S\]

(π′ 가 확률적이면 \(q_\pi(s,\pi'(s))\) 는 \(\E_{\pi'}[q_\pi(s, A_t)\mid S_t = s] = \sum_a \pi'(a\mid s) q_\pi(s,a)\) 라는 뜻)

proof

임의의 \(s \in \S\) 에 대해 (슬라이드 p.30 과 같은 순서)

\[\begin{aligned} v_\pi(s) &= \E_\pi[q_\pi(s, A_t) \mid S_t = s] && \text{①} \\ &\le \E_{\pi'}[q_\pi(s, A_t) \mid S_t = s] && \text{②} \\ &= \E_{\pi'}[R_{t+1} + \gamma v_\pi(S_{t+1}) \mid S_t = s] && \text{③} \\ &\le \E_{\pi'}\big[R_{t+1} + \gamma\, \E_{\pi'}[q_\pi(S_{t+1}, A_{t+1}) \mid S_{t+1}] \,\big|\, S_t = s\big] && \text{④} \\ &= \E_{\pi'}\big[R_{t+1} + \gamma\, \E_{\pi'}\big[\E_\pi[R_{t+2} + \gamma v_\pi(S_{t+2}) \mid S_{t+1}, A_{t+1}] \,\big|\, S_{t+1}\big] \,\big|\, S_t = s\big] && \text{⑤} \\ &= \E_{\pi'}[R_{t+1} + \gamma R_{t+2} + \gamma^2 v_\pi(S_{t+2}) \mid S_t = s] && \text{⑥} \\ &\le \E_{\pi'}[R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots \mid S_t = s] && \text{⑦} \\ &= v_{\pi'}(s). \quad\blacksquare && \text{⑧} \end{aligned}\]

한 줄씩 읽기

줄무엇을 했나
①정의: \(v_\pi(s) = \sum_a \pi(a\mid s)\,q_\pi(s,a)\) 를 기댓값으로 쓴 것
②가정 사용: 첫 행동을 π 대신 π′ 로 골라도 손해가 없다 (\(q_\pi(s,\pi'(s)) \ge v_\pi(s)\))
③\(q_\pi\) 정의: 한 스텝 보상 \(R_{t+1}\) + 그 뒤로 π 를 따른 가치 \(\gamma v_\pi(S_{t+1})\)
④다음 상태 \(S_{t+1}\) 에서 가정을 한 번 더: \(v_\pi(S_{t+1}) \le \E_{\pi'}[q_\pi(S_{t+1}, A_{t+1}) \mid S_{t+1}]\)
⑤그 \(q_\pi\) 를 정의대로 풀기. 행동 \(A_{t+1}\) 이후는 π 를 따르는 값이라 안쪽은 \(\E_\pi\)
⑥겹친 기댓값을 하나로 합치기 (전기댓값 법칙) → 두 스텝을 π′ 로 행동한 셈
⑦②~⑥ 을 무한히 반복 → 모든 행동을 π′ 로
⑧“처음부터 끝까지 π′ 를 따른 기대 리턴” = \(v_{\pi'}(s)\) 의 정의
한 줄 요약π ≤ “1스텝만 π′” ≤ “2스텝 π′” ≤ ⋯ ≤ “전부 π′” = π′. 한 스텝만 \(\pi'\)를 따르고 나머진 \(\pi\)를 따라도 손해가 없다면, 계속 \(\pi'\)를 따르면 더 좋다.

Why Policy Iteration Reaches \(\pi_*\) 수렴 논리

04장 원래 위치 → p.31 – 32

3장의 정리(\(q_\pi(s^*,a^*) \ge v_\pi(s^*)\)이면 그 상태만 바꾼 정책이 더 좋다)를 모든 상태에 동시에 적용한 게 그리디 개선이에요.

  • \(\pi'(s) = \argmax_{a \in \A} q_\pi(s,a)\) 로 개선. 그러면 \(q_\pi(s,\pi'(s)) = \max_a q_\pi(s,a) \ge v_\pi(s)\) → 정책 개선 정리에 의해 \(v_{\pi'} \ge v_\pi\).
  • 결정적 정책은 유한 개이고, \(\pi' = \pi\)가 될 때까지 매 단계가 엄격히 개선되므로 유한 번 안에 끝난다.
  • 개선이 멈추면:
    \[q_\pi(s, \pi'(s)) = \max_{a \in \A} q_\pi(s,a) = q_\pi(s, \pi(s)) = v_\pi(s)\]
    → 이건 바로 벨만 최적 방정식 \(v_\pi(s) = \max_a q_\pi(s,a)\)!
  • 따라서 모든 \(s\)에 대해 \(v_\pi(s) = v_*(s)\) (유일한 고정점이니까), 즉 \(\pi\)는 최적 정책.

Find Optimal Value Function using DP

04장 원래 위치 → p.36

\(k\)-스텝 최적 기대 리턴:

\[V_k(s) = \max_\pi \E_\pi\Big[\sum_{i=0}^{k-1}\gamma^i R_{t+1+i} \;\Big|\; S_t = s\Big]\]
\[V_k(s) = \max_a \sum_{s'} p(s'\mid s,a)\big[r(s,a,s') + \gamma V_{k-1}(s')\big], \qquad \lim_{k\to\infty} V_k(s) = v_*(s)\]
  • Substructure: 최적 \(k\)-스텝 리턴 = 가장 좋은 첫 행동의 보상 + 다음 상태의 최적 \((k-1)\)-스텝 리턴 (최적성의 원리, principle of optimality)
  • Table structure: \(V_{k-1}(s')\)는 한 번 계산되어 여러 \(s\)가 재사용
  • Bottom-up: \(V_0 \equiv 0\)에서 \(V_1, V_2, \dots\)
수렴 근거3장에서 증명한 대로 벨만 최적 연산자 \(T\)는 \(\gamma\)-축약사상 (p.37 증명 동일) → 바나흐 고정점 정리 (p.38) → 벨만 최적 방정식은 고정점 \(v_*\)를 정의하고 \(V_k \to v_*\).

Law of Large Numbers 큰 수의 법칙 (LLN)

Evaluate Value Function using MC 증분 평균

\[v_\pi(s) = \E_\pi[G \mid s]\]
\[V_n(s) = \frac{G^{(1)} + G^{(2)} + \cdots + G^{(n)}}{n}\]

ε-Greedy Policy Improvement 정리 + 증명

05장 원래 위치 → p.25
theorem

임의의 ε-greedy 정책 \(\pi\)에 대해, \(q_\pi\)에 대한 ε-greedy 정책 \(\pi'\)는 개선이다: \(v_{\pi'}(s) \ge v_\pi(s)\).

proof
\[\begin{aligned} q_\pi(s, \pi'(s)) &= \sum_{a \in \A} \pi'(a\mid s)\, q_\pi(s,a) \\ &= \frac{\varepsilon}{m}\sum_{a \in \A} q_\pi(s,a) + (1-\varepsilon)\max_{a \in \A} q_\pi(s,a) \\ &\ge \frac{\varepsilon}{m}\sum_{a \in \A} q_\pi(s,a) + (1-\varepsilon)\sum_{a \in \A}\frac{\pi(a\mid s) - \frac{\varepsilon}{m}}{1-\varepsilon}\, q_\pi(s,a) \\ &= \sum_{a \in \A} \pi(a\mid s)\, q_\pi(s,a) = v_\pi(s) \end{aligned}\]

부등호: \(\frac{\pi(a\mid s) - \varepsilon/m}{1-\varepsilon}\)는 합이 1인 음이 아닌 가중치(π가 ε-greedy니까 \(\pi(a\mid s) \ge \varepsilon/m\))라서 그 가중평균은 max보다 작거나 같다.

그러면 정책 개선 정리(\(q_\pi(s,\pi'(s)) \ge v_\pi(s)\ \forall s \Rightarrow v_{\pi'}(s) \ge v_\pi(s)\ \forall s\))에 의해 \(v_{\pi'} \ge v_\pi\). \(\blacksquare\)

ε-soft Optimal Policy

05장 원래 위치 → p.26
definition

ε-soft 정책: 어떤 \(\varepsilon \gt 0\)에 대해 모든 상태·행동에서 \(\pi(a\mid s) \ge \dfrac{\varepsilon}{|\A(s)|}\)인 정책.

definition

ε-soft 최적 정책:

\[\pi^*_\varepsilon \in \argmax_{\pi \in \Pi_\varepsilon} v_\pi(s),\ \forall s \in \S, \qquad \Pi_\varepsilon = \Big\{\pi \;\Big|\; \pi(a\mid s) \ge \frac{\varepsilon}{|\A(s)|},\ \forall s \in \S, a \in \A(s)\Big\}\]

ε를 상수로 고정하면 MC 정책 이터레이션과 MC 제어 모두 (진짜 최적이 아닌) ε-soft 최적 정책으로 수렴해요. 항상 ε만큼 랜덤하게 행동해야 하니까 그 제약 안에서의 최선.

Non-Stationary Problem 비정상 문제

05장 원래 위치 → p.40 – 42

큰 수의 법칙은 표본이 i.i.d.일 때 성립해요. 그런데 \(G^{(n)}\)들이 동일한 분포에서 나올까요?

아니요. 정책 \(\pi(a\mid s)\)가 계속 바뀌니까 리턴의 분포도 계속 바뀌어요 → 비정상(non-stationary).

해결: 표본평균 대신 지수이동평균(exponential moving average)을 사용:

\[Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \frac{1}{N(S_t,A_t)}\big(G_t - Q(S_t,A_t)\big) \quad\Longrightarrow\quad Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \alpha\big(G_t - Q(S_t,A_t)\big)\]

왜 “지수” 이동평균?

\[\begin{aligned} Q_n(s,a) &= \alpha G^{(n)} + (1-\alpha) Q_{n-1}(s,a) \\ &= \alpha G^{(n)} + (1-\alpha)\big[\alpha G^{(n-1)} + (1-\alpha) Q_{n-2}(s,a)\big] \\ &= \alpha G^{(n)} + \alpha(1-\alpha) G^{(n-1)} + (1-\alpha)^2 Q_{n-2}(s,a) \\ &= \alpha G^{(n)} + \alpha(1-\alpha) G^{(n-1)} + \alpha(1-\alpha)^2 G^{(n-2)} + \cdots + \alpha(1-\alpha)^{n-1} G^{(1)} + (1-\alpha)^n Q_0(s,a) \end{aligned}\]

가중치의 합: \(\sum_{i=1}^{n} \alpha(1-\alpha)^{n-i} + (1-\alpha)^n = 1\). 오래된 리턴일수록 가중치가 지수적으로 작아져요 → 최근 데이터를 더 믿음!

Bias/Variance Trade-Off 편향과 분산

06장 원래 위치 → p.9 – 10
  • 리턴 \(G_t = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{T-1}R_T\)는 \(v_\pi(S_t)\)의 불편(unbiased) 추정치
  • 진짜 TD 타깃 \(R_{t+1} + \gamma v_\pi(S_{t+1})\)도 \(v_\pi(S_t)\)의 불편 추정치
  • 하지만 실제 TD 타깃 \(R_{t+1} + \gamma V(S_{t+1})\)은 편향된(biased) 추정치 — 부트스트래핑(추정치 \(V\)를 쓰니까)
  • TD 타깃은 리턴보다 분산이 훨씬 작다:
    • 리턴은 많은 무작위 행동·전이·보상에 의존
    • TD 타깃은 무작위 행동·전이·보상 하나에만 의존

MC: 높은 분산, 편향 0

  • 수렴 성질이 좋다
  • 초기값에 그다지 민감하지 않다
  • 이해하고 쓰기 매우 간단

TD: 낮은 분산, 약간의 편향

  • 보통 MC보다 효율적
  • TD(0)는 \(v_\pi(s)\)로 수렴
  • 초기값에 더 민감

Convergence of SARSA

06장 원래 위치 → p.19
theorem

SARSA는 다음 조건에서 최적 행동가치함수로 수렴한다, \(Q(s,a) \to q_*(s,a)\):

  • 정책 수열 \(\pi_t(a\mid s)\)가 GLIE
  • 스텝 크기 \(\alpha_t\)가 Robbins-Monro 수열:
    \[\sum_{t=1}^{\infty} \alpha_t = \infty, \qquad \sum_{t=1}^{\infty} \alpha_t^2 \lt \infty\]
Robbins-Monro 직관첫째 조건: 스텝 합이 무한 → 초기값이 아무리 멀어도 도달할 수 있을 만큼 충분히 움직임. 둘째 조건: 스텝이 충분히 빨리 작아짐 → 노이즈가 결국 사라져 한 점에 수렴. 예: \(\alpha_t = 1/t\) ✓, 상수 α ✗(둘째 조건 위반).

Convergence of Q-Learning

06장 원래 위치 → p.33
theorem

Q-learning은 다음 조건에서 최적 행동가치함수로 수렴한다, \(Q(s,a) \to q_*(s,a)\):

  • (행동) 정책 수열 \(\pi_t(a\mid s)\)가 GLIE
  • 스텝 크기가 Robbins-Monro: \(\sum_t \alpha_t = \infty,\ \sum_t \alpha_t^2 \lt \infty\)

Averaging n-Step Returns

06장 원래 위치 → p.43
  • 서로 다른 \(n\)의 n-step 리턴을 평균 낼 수 있다.
  • Complex backup: 더 단순한 백업들을 평균한 백업. 예) 2-step과 4-step 리턴의 평균 \(\tfrac12 G^{(2)} + \tfrac12 G^{(4)}\)
  • 모든 타임스텝의 정보를 효율적으로 합칠 수는 없을까? → TD(λ)

TD(λ) λ-return, forward view

06장 원래 위치 → p.44

\(\lambda\)-리턴 \(G_t^\lambda\)는 모든 n-step 리턴 \(G_t^{(n)}\)을 가중치 \((1-\lambda)\lambda^{n-1}\)로 합친 것 (\(0 \le \lambda \le 1\)):

\[G_t^\lambda = (1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1} G_t^{(n)} = (1-\lambda)\sum_{n=1}^{T-t-1}\lambda^{n-1}G_t^{(n)} + \lambda^{T-t-1}G_t\]

(에피소드가 \(T\)에서 끝나면 \(n \ge T-t\)인 모든 n-step 리턴이 실제 리턴 \(G_t\)와 같아서 그 가중치들이 \(\lambda^{T-t-1}\)로 모임.)

Forward-view TD(λ):

\[V(S_t) \leftarrow V(S_t) + \alpha\big(\underbrace{G_t^\lambda - V(S_t)}_{\lambda\text{-error}}\big)\]

\(\text{TD}(0) = \text{TD}\), \(\text{TD}(1) = \text{MC}\)

근데 문제가…Forward view는 \(G_t^\lambda\)를 계산하려면 결국 미래를 다 봐야 해서 MC처럼 에피소드 끝까지 기다려야 해요 → backward view로 해결!

Backward View of TD(λ): Episodic Task

06장 원래 위치 → p.45

TD 오차: \(\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\). λ-오차를 펼쳐서 정리하면

\[\begin{aligned} G_t^\lambda - V(S_t) = -V(S_t) &+ (1-\lambda)\lambda^0\,[R_{t+1} + \gamma V(S_{t+1})] \\ &+ (1-\lambda)\lambda^1\,[R_{t+1} + \gamma R_{t+2} + \gamma^2 V(S_{t+2})] \\ &+ (1-\lambda)\lambda^2\,[R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \gamma^3 V(S_{t+3})] + \cdots \\ &+ \lambda^{T-t-1}\,[R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{T-t-1}R_T] \end{aligned}\]

보상 \(R_{t+k}\)끼리, \(V(S_{t+k})\)끼리 모으면 (\(R_{t+k}\)의 계수는 \((\gamma\lambda)^{k-1}\), \(V(S_{t+k})\)는 \(+(\gamma\lambda)^{k-1}\gamma\)와 \(-(\gamma\lambda)^{k}\) 두 번 나옴):

\[\begin{aligned} &= (\gamma\lambda)^0\,[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)] \\ &\quad+ (\gamma\lambda)^1\,[R_{t+2} + \gamma V(S_{t+2}) - V(S_{t+1})] \\ &\quad+ \cdots + (\gamma\lambda)^{T-t-1}\,[R_T + \gamma V(S_T) - V(S_{T-1})] \\ &= \delta_t + (\gamma\lambda)\delta_{t+1} + (\gamma\lambda)^2\delta_{t+2} + \cdots + (\gamma\lambda)^{T-t-1}\delta_{T-1} \\ &= \sum_{k=t}^{T-1}(\gamma\lambda)^{k-t}\delta_k = \sum_{k=t}^{T}(\gamma\lambda)^{k-t}\delta_k \quad (\delta_T = 0) \end{aligned}\]
key result

λ-오차 = 앞으로 나올 TD 오차들의 \((\gamma\lambda)\)-할인 합. 즉 미래 대신 매 스텝 나오는 TD 오차 \(\delta_k\)를 과거 상태들에 나눠 주면 같은 결과!

Backward View of TD(λ): Continuous Task

06장 원래 위치 → p.46

종료가 없는 경우도 똑같이 무한히 펼쳐서 정리하면:

\[G_t^\lambda - V(S_t) = \delta_t + (\gamma\lambda)\delta_{t+1} + (\gamma\lambda)^2\delta_{t+2} + \cdots = \sum_{k=t}^{\infty}(\gamma\lambda)^{k-t}\delta_k\]

Eligibility Trace 적격 흔적

06장 원래 위치 → p.47

각 상태가 지금 나온 TD 오차에 대해 “얼마나 책임이 있는지”를 기록하는 값 \(E_t(s) \in \R^+\).

  • 초기값은 0: \(E_0(s) = 0,\ \forall s \in \S\)
  • 매 스텝, 방문하지 않은 모든 상태의 trace는 \(\gamma\lambda\)배로 감쇠: \(E_t(s) = \gamma\lambda E_{t-1}(s),\ \forall s \ne S_t\)
  • 시각 \(t\)에 방문한 상태 \(S_t\)의 trace: \(E_t(S_t) = \gamma\lambda E_{t-1}(S_t) + 1\)
  • \(\lambda\): trace-decay parameter

한 줄로: \(E_t(s) = \gamma\lambda E_{t-1}(s) + \mathbf{1}(S_t = s)\). 그리고 backward TD(λ)는 매 스텝 모든 상태를

\[V(s) \leftarrow V(s) + \alpha\,\delta_t\,E_t(s), \quad \forall s\]

로 업데이트해요. 최근에 자주 방문한 상태일수록 큰 몫을 받아요 (빈도 + 최근성 휴리스틱).

Forwards and Backwards TD(λ) 둘은 같다

06장 원래 위치 → p.48

상태 \(s\)가 에피소드 중 시각 \(k\)에 한 번 방문되었다고 하면, trace는 방문 이후 시간을 할인해요:

\[E_t(s) = \gamma\lambda E_{t-1}(s) + \mathbf{1}(S_t = s) = \begin{cases} 0 & \text{if } t \lt k \\ (\gamma\lambda)^{t-k} & \text{if } t \ge k \end{cases}\]

Backward TD(λ)의 업데이트를 에피소드 동안 누적하면:

\[\sum_{t=1}^{T}\alpha\,\delta_t\,E_t(s) = \alpha\sum_{t=k}^{T}(\gamma\lambda)^{t-k}\delta_t = \alpha\big(G_k^\lambda - V(S_k)\big)\]
  • 에피소드가 끝날 때 backward view는 λ-리턴의 총 오차를 정확히 누적한다 → forward view와 동일!
  • 같은 상태 \(s\)를 여러 번 방문하면 \(E_t(s)\)가 여러 오차를 누적한다 (accumulating trace).
    • Replacing eligibility trace: \(E_t(s) = \mathbf{1}(S_t = s)\) 처럼 방문 시 1로 리셋하는 변형
