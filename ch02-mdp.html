part 1introduction to mdp

Stochastic Process 확률과정

p.2
definition

확률과정(stochastic process, SP)은 확률변수들의 무한한 모음(collection)이다.

  • 이산시간 SP: \(\{X_n,\ n = 0,1,2,\dots\}\)
  • 연속시간 SP: \(\{X(t),\ t \ge 0\}\)

즉, “시간에 따라 값이 랜덤하게 변하는 것”을 시간 인덱스가 붙은 확률변수들의 줄로 표현한 거예요.

예시

  • \(X_n\) = \(n\)일째의 최고 기온 (이산)
  • \(X(t)\) = 시각 \(t\)에 대기열에 있는 고객 수 (연속)
  • \(X_n\) = \(n\)일째 수업에 출석한 학생 수
  • \(X_n\) = 매일 장 마감 시점의 내 주식 가치
  • \(X(t)\) = 시각 \(t\)의 강의실 온도
  • \(X(t)\) = 어떤 실험에서 직선 위 점 \(t\)에서의 최고 온도 (여기서 \(t\)는 시간이 아니라 위치! 인덱스가 꼭 시간일 필요는 없음)

State Space & Markov Chain 상태공간과 마르코프 체인

p.3
definition
  • \(X_n\) (또는 \(X(t)\))을 시각 \(n\)(또는 \(t\))에서 SP의 상태(state)라고 한다.
  • 확률변수 \(X_n\)이 가질 수 있는 모든 값의 집합을 SP의 상태공간(state space)이라고 한다.
definition

가산(countable) 상태공간을 가지는 이산시간 SP \(\{X_n\}\)가 다음을 만족하면 마르코프 체인(Markov chain)이라 한다.

\[P(X_{n+1}=j \mid X_n=i, X_{n-1}=i_{n-1},\dots,X_0=i_0) = P(X_{n+1}=j \mid X_n=i)\]
해석하면?
  • 가장 최근 상태 하나만 알면 미래를 예측할 수 있다 (그 이전 상태들은 필요 없다).
  • 과거 상태들과 현재 상태가 주어졌을 때, 미래 상태의 조건부 분포는 과거와 무관하고 현재 상태에만 의존한다.

State Transition Matrix 상태 전이 행렬

p.4
definition

한 단계(one-step) 전이확률은

\[P_{ss'} = P(X_{n+1}=s' \mid X_n = s)\]
  • 각 행의 합은 1이어야 한다: \(\sum_{s'} P_{ss'} = 1,\ \forall s\) (어디론가는 반드시 가니까)
  • 한 단계 전이확률들을 모은 행렬을 \(P\)라고 쓴다.
\[P \equiv \begin{bmatrix} P_{00} & P_{01} & P_{02} & \cdots \\ P_{10} & P_{11} & P_{12} & \cdots \\ \vdots & \vdots & \vdots & \ddots \end{bmatrix}\]

예시: Random Walk

상태공간이 정수 \(i = 0, \pm1, \pm2, \dots\)인 마르코프 체인이 어떤 \(0 \lt p \lt 1\)에 대해

\[P_{i,i+1} = p = 1 - P_{i,i-1}\]

를 만족하면 랜덤 워크라고 한다. 매 단계 확률 \(p\)로 오른쪽, \(1-p\)로 왼쪽으로 한 칸 이동하는 것.

Markov Process 마르코프 과정

p.5
definition

마르코프 과정(Markov Process, = Markov Chain)은 튜플 \(\langle \S, \P \rangle\)이다.

  • \(\S\): (유한한) 상태들의 집합 (state space)
  • \(\P\): 상태 전이 확률 행렬, \(\P_{ss'} = P[S_{t+1}=s' \mid S_t = s]\)

예시: 택시 기사 (Taxi Driver)

택시 기사가 손님을 태우며 돈을 버는 상황. 상태는 3개: Airport, Seomyeon, Haeundae.

from \ toAirportSeomyeonHaeundae
Airport0.70.10.2
Seomyeon0.30.20.5
Haeundae0.40.20.4

Markov Reward Process 마르코프 보상 과정

p.6

손님이 돈 낸 걸 어떻게 표현하지? → 보상(reward)을 추가!

definition

MRP는 튜플 \(\langle \S, \P, \Rc, \gamma \rangle\)이다.

  • \(\S\): (유한한) 상태 집합
  • \(\P\): 상태 전이 확률 행렬, \(\P_{ss'} = P[S_{t+1}=s' \mid S_t=s]\)
  • \(\Rc\): 보상 함수, \(\Rc_s = \E[R_{t+1} \mid S_t = s]\)
  • \(\gamma\): 할인율(discount factor), \(\gamma \in [0,1]\)

택시 예시에 보상을 붙이면: 같은 지역에 머무르면 \(-1\) (공치는 시간), 서면↔공항은 \(+10\), 서면↔해운대는 \(+5\), 공항↔해운대는 \(+20\) (장거리 손님).

from → to확률, 보상
Airport → Airport / Seomyeon / Haeundae0.7, −1  /  0.1, +10  /  0.2, +20
Seomyeon → Seomyeon / Airport / Haeundae0.2, −1  /  0.3, +10  /  0.5, +5
Haeundae → Haeundae / Seomyeon / Airport0.4, −1  /  0.2, +5  /  0.4, +20

Markov Decision Process 마르코프 결정 과정

p.7

만약 기사가 고객을 안 태우고 이동한다면? → 행동(action)을 추가!

definition

MDP는 튜플 \(\langle \S, \A, \P, \Rc, \gamma \rangle\)이다.

  • \(\S\): 유한한 상태 집합
  • \(\A\): 유한한 행동(action) 집합
  • \(\P\): 상태 전이 확률 행렬, \(\P^{a}_{ss'} = P[S_{t+1}=s' \mid S_t = s, A_t = a]\)
  • \(\Rc\): 보상 함수, \(\Rc^{a}_{s} = \E[R_{t+1} \mid S_t = s, A_t = a]\)
  • \(\gamma\): 할인율 \(\gamma \in [0,1]\)

MRP와의 차이: 전이확률과 보상이 이제 행동 \(a\)에도 의존해요. 택시 기사는 두 종류 행동을 할 수 있어요.

  • Wait: 그 자리에서 손님을 기다림 → 위 MRP처럼 확률적으로 이동하며 보상
  • Move: 빈 차로 다른 지역으로 이동 → 확정적으로 이동, 보상 \(-5\)
필기 예시 \(r(\text{Airport}, \text{Wait}) = 0.2 \times 20 + 0.1 \times 10 + 0.7 \times (-1) = 4.3\)

Introduction to MDPs 왜 MDP인가

p.8
  • MDP는 강화학습의 환경(environment)을 형식적으로 기술한다.
  • 환경이 완전 관측 가능(fully observable)한 경우를 다룬다.
  • 거의 모든 RL 문제는 MDP로 형식화할 수 있다.
    • 최적 제어(optimal control)는 주로 연속 MDP를 다룬다.
    • 부분 관측 문제(POMDP)도 MDP로 변환할 수 있다.
    • 밴딧(Bandit) 문제는 상태가 하나인 MDP다.

part 2markov decision process

Sequential Decision Process 순차적 의사결정

p.10 – 12

매 시점 \(t\)마다:

  • 에이전트가 관측 \(O_t\)와 보상 \(R_t\)를 받는다.
  • 에이전트가 행동 \(A_t\)를 한다.
  • 세계(환경)는 \(A_t\)를 받아 갱신되고, 관측 \(O_{t+1}\)과 보상 \(R_{t+1}\)을 내보낸다.

History

히스토리는 관측·행동·보상의 전체 수열: \(H_t = O_1, R_1, A_1, \dots, A_{t-1}, O_t, R_t\)

State

상태는 다음에 무슨 일이 일어날지 결정하는 데 쓰는 정보로, 히스토리의 함수다: \(S_t = f(H_t)\)

포인트히스토리 전체를 들고 다니면 너무 크니까, 미래 예측에 필요한 만큼만 요약한 것이 상태!

Markov Property 마르코프 성질

p.13

“The future is independent of the past given the present”

definition

상태 \(S_t\)가 마르코프이다 ⟺

\[P[S_{t+1} \mid S_t, A_t] = P[S_{t+1} \mid S_1, A_1, \dots, S_t, A_t]\]

유한 MDP(Finite MDP)란 마르코프 성질을 만족하는 순차적 의사결정 과정이다.

definition

Finite MDP는 튜플 \(\langle \S, \A, \P, \Rc, \gamma \rangle\):

  • \(\S\) 유한 상태 집합, \(\A\) 유한 행동 집합
  • \(\P^{a}_{ss'} = P[S_{t+1}=s' \mid S_t=s, A_t=a]\)
  • \(\Rc^{a}_{s} = \E[R_{t+1} \mid S_t=s, A_t=a]\)
  • \(\gamma \in [0,1]\)

Timestep of MDP MDP 한 스텝

p.14, p.21

상태 \(S_t\)에서 에이전트가 행동 \(A_t\)를 하면 환경이 보상 \(R_{t+1}\)과 다음 상태 \(S_{t+1}\)을 준다:

\[S_0, A_0, R_1, S_1, A_1, R_2, S_2, \dots\]

그럼 자연스럽게 세 가지 질문이 생겨요. 이 장의 나머지가 이 질문에 대한 답이에요.

  1. 상태는 어떻게 전이되나? → 상태 전이 (State Transition)
  2. 보상은 어떻게 주어지나? → 보상 함수 (Reward Function)
  3. 에이전트는 행동을 어떻게 고르나? → 정책 (Policy) — Part 3

State Transition 상태 전이

p.15 – 16

결정적 (Deterministic)

상태 전이 함수로 다음 상태가 하나로 정해짐

\[s' = f(s, a)\]

확률적 (Stochastic)

상태 전이 확률 (마르코프 성질 포함)

\[p(s' \mid s,a) = P[S_{t+1}=s' \mid S_t=s, A_t=a] = \P^{a}_{ss'}\]

예시: 게임 장비 강화 (15성 → 16성)

“강화(Enhancement)” 행동을 하면: 성공 30% → 16성, 실패(유지) 68% → 15성 그대로, 파괴 2% → Destruction.

Reward Function 보상 함수

p.17
reward hypothesis

“우리가 목표나 목적이라고 부르는 모든 것은, 받게 되는 스칼라 신호(=보상)의 누적합의 기댓값을 최대화하는 것으로 잘 표현될 수 있다.”

보상 함수는 두 가지 형태로 쓸 수 있어요.

\[r(s,a) = \E[R_{t+1} \mid S_t=s, A_t=a] = \Rc^{a}_{s} = \sum_{r} r \sum_{s'} p(s', r \mid s, a)\]
\[r(s,a,s') = \E[R_{t+1} \mid S_t=s, A_t=a, S_{t+1}=s'] = \sum_{r} r\,\frac{p(s', r \mid s,a)}{p(s' \mid s,a)}\]

강화 예시에서 보상을 “유지 0, 성공 +1, 파괴 −15”라고 하면:

\[r(15, \text{Enh.}) = 0.68 \times 0 + 0.3 \times 1 + 0.02 \times (-15) = 0\]

→ 기대 보상이 0! 강화할 이유가… 🤔

Returns 리턴

p.18
definition

리턴 \(G_t\)는 시점 \(t\)부터의 할인된 보상의 총합이다.

\[G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}\]
  • 할인율 \(\gamma \in [0,1]\)은 미래 보상의 현재 가치.
  • \(k+1\) 스텝 뒤에 받는 보상 \(R\)의 가치는 \(\gamma^k R\).
  • 즉, 지연된 보상보다 즉각적인 보상을 더 높게 평가한다.
    • \(\gamma\)가 0에 가까우면 “근시안적(myopic)” 평가
    • \(\gamma\)가 1에 가까우면 “원시안적(far-sighted)” 평가

Episodic Task vs Continuous Task

p.19

Episodic task

  • 시작점과 끝점이 명확한 과제
  • 에피소드: 시작점부터 가장 가까운 종료점까지의 상태 수열
  • 예: 체스 한 판, 미로 찾기, 정해진 목적지까지 자율주행

Continuous task

  • 미리 정해진 끝이 없는 과제
  • \(\gamma \ne 1\) 이어야 함 (안 그러면 리턴이 발산)
  • 예: 주식 트레이딩 에이전트, 공장 제어 시스템, 신호등 제어 (6장: 로봇 청소기)

Why discount? 왜 할인할까

p.20
  1. 수학적으로 편리하다.
  2. 순환하는 마르코프 과정에서 리턴이 무한대가 되는 것을 막는다.
  3. 미래에 대한 불확실성을 반영한다.
  4. 보상이 금전이라면, 당장 받는 돈이 이자를 더 벌 수 있다.
  5. 동물/사람의 행동도 즉각적인 보상을 선호한다.
  6. 모든 수열이 종료된다면 할인하지 않는(\(\gamma=1\)) MRP를 쓰는 것도 가능하다.
수식으로 확인보상이 최대 \(R_{\max}\)로 유계이고 \(\gamma \lt 1\)이면 \(|G_t| \le \sum_k \gamma^k R_{\max} = \dfrac{R_{\max}}{1-\gamma}\) 로 유한!

part 3rl agent

Major Components of an RL Agent 에이전트의 3요소

p.23

“The agent’s job is to maximize cumulative reward”

① Policy \(\pi: \S \to \A\)

에이전트의 행동 함수 — 행동을 어떻게 고를지 결정.

  • 결정적 정책: \(\pi(s) = a\)
  • 확률적 정책: \(\pi(a \mid s) = P[A_t=a \mid S_t=s]\)

② Value function \(v\)

각 상태(및/또는 행동)가 얼마나 좋은지. 미래 보상에 대한 예측.

③ Model

에이전트가 가진 환경에 대한 표현 — 환경이 다음에 무엇을 할지 예측.

  • Transitions: \(\P\)가 다음 상태를 예측
  • Rewards: \(\Rc\)가 다음 (즉각) 보상을 예측

Policies 정책

p.24
definition

정책 \(\pi\)는 상태가 주어졌을 때 행동에 대한 분포이다.

\[\pi(a \mid s) = P[A_t = a \mid S_t = s]\]
  • 정책은 에이전트의 행동을 완전히 정의한다.
  • MDP 정책은 (히스토리가 아니라) 현재 상태에만 의존한다. → 마르코프 성질 덕분!
  • MDP의 목표는 누적 보상을 최대화하는 최적 정책을 찾는 것.

Value Function 가치함수

p.25
definition · state-value

MDP의 상태가치함수 \(v_\pi(s)\): 상태 \(s\)에서 시작해서 정책 \(\pi\)를 따를 때의 기대 리턴

\[v_\pi(s) = \E_\pi[G_t \mid S_t = s]\]
definition · action-value

행동가치함수 \(q_\pi(s,a)\): 상태 \(s\)에서 행동 \(a\)를 하고, 그 뒤로 정책 \(\pi\)를 따를 때의 기대 리턴

\[q_\pi(s,a) = \E_\pi[G_t \mid S_t = s, A_t = a]\]

둘의 관계 — 상태가치는 행동가치를 정책 확률로 평균낸 것:

\[v_\pi(s) = \sum_{a \in \A(s)} \pi(a \mid s)\, q_\pi(s,a), \quad \forall s \in \S\]

Example 사과 줍기 로봇

p.26
  • State: 0 (왼쪽 칸), 1 (오른쪽 칸, 사과)
  • Action: Left, Right
  • Reward: 벽에 부딪히면 −1, 사과를 얻으면 +1, 그 외 0
  • \(\gamma = 0.9\)

0에서 R → 1로 가며 사과 획득(+1). 1에서 L → 0으로 이동(0). 0에서 L, 1에서 R은 벽(−1, 제자리). 사과는 다시 생긴다고 생각하면 돼요.

π(0)π(1)\(v_\pi(0)\)
Policy 1LL−10
Policy 2LR−10
Policy 3RL5.26
Policy 4RR−8

계산 과정 (필기)

  • Policy 1 (L, L): 계속 벽에 박음 → \(-1 - 0.9 - 0.9^2 - \cdots = \dfrac{-1}{1-0.9} = -10\)
  • Policy 3 (R, L): +1, 0, +1, 0, … → \(1 + 0.9\cdot 0 + 0.9^2 \cdot 1 + \cdots = \dfrac{1}{1-0.9^2} = 5.26\)
  • Policy 4 (R, R): +1 후 계속 벽 → \(1 - 0.9 - 0.9^2 - \cdots = 1 - \dfrac{0.9}{1-0.9} = -8\)
포인트가치함수가 있으면 정책끼리 비교가 가능해진다! → Policy 3이 4개 중 최고.

Optimal Value Function 최적 가치함수

p.27
definition

최적 상태가치함수 \(v_*(s)\)는 모든 정책에 대한 가치함수의 최댓값

\[v_*(s) = \max_\pi v_\pi(s)\]
definition

최적 행동가치함수 \(q_*(s,a)\)는 모든 정책에 대한 행동가치함수의 최댓값

\[q_*(s,a) = \max_\pi q_\pi(s,a)\]

최적 가치함수는 MDP에서 낼 수 있는 “최선의 성능”을 나타내고, 이걸 알면 MDP는 “풀렸다(solved)”고 할 수 있어요.

Optimal Policy 최적 정책

p.28

정책들 사이에 부분 순서(partial ordering)를 정의:

\[\pi \ge \pi' \quad \text{if} \quad v_\pi(s) \ge v_{\pi'}(s),\ \forall s\]
theorem

모든 MDP에 대해

  • 다른 모든 정책보다 좋거나 같은 최적 정책 \(\pi_*\)가 존재한다: \(\pi_* \ge \pi,\ \forall \pi\)
  • 모든 최적 정책은 최적 가치함수를 달성한다: \(v_{\pi_*}(s) = v_*(s)\)
  • 모든 최적 정책은 최적 행동가치함수를 달성한다: \(q_{\pi_*}(s,a) = q_*(s,a)\)

즉, 최적 정책 \(\pi_*\)는

\[v_{\pi_*}(s) \ge v_\pi(s),\ \forall s \in \S \qquad q_{\pi_*}(s,a) \ge q_\pi(s,a),\ \forall s \in \S, a \in \A\]
왜 “부분” 순서?정책 A가 어떤 상태에선 낫고 다른 상태에선 못할 수 있어서, 모든 정책 쌍이 비교 가능한 건 아니에요. 그래도 “모든 상태에서 최고”인 정책은 항상 존재한다는 게 이 정리의 핵심!

Types of RL Agents 에이전트 분류

p.29 – 31

모델 유무로

  • Model-based: 모델을 명시적으로 가짐. 정책/가치함수는 있을 수도 없을 수도.
  • Model-free: 가치함수 및/또는 정책을 명시적으로 가짐. 모델 없음.

무엇을 학습하나로

  • Value-based: 가치함수만 명시적, 정책은 암묵적 (예: 가치가 최대인 행동 선택)
  • Policy-based: 정책만 명시적, 가치함수 없음
  • Actor-critic: 정책과 가치함수 둘 다

\(\gamma = 0.5\), 보상이 1, 2, 4 순서로 들어올 때 \(G_t\)는?
\(1 + 0.5 \cdot 2 + 0.25 \cdot 4 = 3\)

끝이 없어서 보상이 무한히 더해지므로 리턴이 발산할 수 있어요. 그래서 \(\gamma \ne 1\).
\(v_\pi(s)\)와 \(q_\pi(s,a)\)의 관계식은?
\(v_\pi(s) = \sum_a \pi(a\mid s)\, q_\pi(s,a)\)
