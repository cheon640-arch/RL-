MDP\(\langle \S, \A, \P, \Rc, \gamma\rangle\), \(\P^a_{ss'} = P[S_{t+1}=s'\mid S_t=s, A_t=a]\)02
Return\(G_t = \sum_{k=0}^\infty \gamma^k R_{t+k+1} = R_{t+1} + \gamma G_{t+1}\)02
가치함수\(v_\pi(s) = \E_\pi[G_t\mid S_t=s]\), \(q_\pi(s,a) = \E_\pi[G_t\mid S_t=s,A_t=a]\), \(v_\pi = \sum_a \pi q_\pi\)02
벨만 기대 (v)\(v_\pi(s) = \sum_a\sum_{s'}\pi(a\mid s)p(s'\mid s,a)[r + \gamma v_\pi(s')]\)03
벨만 기대 (q)\(q_\pi(s,a) = \sum_{s'}p(s'\mid s,a)[r + \gamma\sum_{a'}\pi(a'\mid s')q_\pi(s',a')]\)03
행렬 해\(v_\pi = (I - \gamma\P^\pi)^{-1}\Rc^\pi\)03
벨만 최적 (v*)\(v_*(s) = \max_a\sum_{s'}p(s'\mid s,a)[r + \gamma v_*(s')]\)03
벨만 최적 (q*)\(q_*(s,a) = \sum_{s'}p(s'\mid s,a)[r + \gamma\max_{a'}q_*(s',a')]\)03
축약사상\(\|Tv - Tv'\|_\infty \le \gamma\|v - v'\|_\infty\) → 바나흐: 유일 고정점, 반복 수렴03·04
정책 평가\(v_{k+1}(s) = \sum_a\pi(a\mid s)\sum_{s'}p[r + \gamma v_k(s')]\)04
정책 개선\(\pi'(s) = \argmax_a q_\pi(s,a)\); \(q_\pi(s,\pi'(s)) \ge v_\pi(s) \Rightarrow v_{\pi'} \ge v_\pi\)04
가치 이터레이션\(v_{k+1}(s) = \max_a\sum_{s'}p[r + \gamma v_k(s')]\)04
MC (증분)\(Q(S_t,A_t) \leftarrow Q + \frac{1}{N}(G_t - Q)\) 또는 \(+\alpha(G_t - Q)\)05
ε-greedy\(\pi(a\mid s) = \varepsilon/m + 1 - \varepsilon\) (greedy), \(\varepsilon/m\) (otherwise)05
GLIE\(N_k(s,a)\to\infty\), \(\pi_k \to\) greedy (예: \(\varepsilon_k = 1/k\))05
TD(0)\(V(S_t) \leftarrow V(S_t) + \alpha[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)]\)06
SARSA\(Q(S,A) \leftarrow Q(S,A) + \alpha[R + \gamma Q(S',A') - Q(S,A)]\)06
Q-learning\(Q(S,A) \leftarrow Q(S,A) + \alpha[R + \gamma\max_a Q(S',a) - Q(S,A)]\)06
Robbins-Monro\(\sum_t\alpha_t = \infty,\ \sum_t\alpha_t^2 \lt \infty\)06
n-step return\(G_t^{(n)} = R_{t+1} + \cdots + \gamma^{n-1}R_{t+n} + \gamma^n V(S_{t+n})\)06
λ-return\(G_t^\lambda = (1-\lambda)\sum_{n\ge1}\lambda^{n-1}G_t^{(n)}\); TD(0)=TD, TD(1)=MC06
Eligibility trace\(E_t(s) = \gamma\lambda E_{t-1}(s) + \mathbf{1}(S_t=s)\), \(V(s) \leftarrow V(s) + \alpha\delta_t E_t(s)\)06
