DP vs RL planning vs learning

p.4 – 5

DP (Planning, known MDP)

  • MDP를 완전히 아는 상태에서 계획(planning)
  • planning = 모델이 만든 시뮬레이션 경험에 백업 연산을 적용해 가치함수를 계산

  • Value Iteration, Policy Iteration

RL (Learning, unknown MDP)

  • MDP를 모르거나(혹은 너무 커서 다룰 수 없을 때) 불완전한 정보로 학습(learning)
  • learning = 환경이 만든 실제 경험을 사용
  • 벨만 방정식을 근사적으로 푼다
  • Monte Carlo Method, Temporal Difference Learning

Monte Carlo Method 몬테카를로 방법

p.8
  • Monte Carlo: 반복적인 무작위 샘플링에 의존해 수치적 결과를 얻는 계산법
  • 몬테카를로 방법은 확률변수의 함수에 대한 기댓값을 무작위 샘플로 추정하는 계산 기법

예: 원의 넓이를 모를 때 정사각형 안에 점을 무작위로 많이 찍고, 원 안에 들어간 비율로 넓이(π)를 추정하는 것.

Law of Large Numbers 큰 수의 법칙 (LLN)

p.9

독립이고 동일한 분포(i.i.d.)를 따르는 표본의 수가 늘어날수록, 표본평균은 모평균(기댓값 \(\mu\))에 가까워진다.

\[P\Big(\lim_{n\to\infty} \frac{1}{n}\sum_{i=1}^{n} X_i = \mu\Big) = 1\]
RL에 적용하면\(v_\pi(s) = \E_\pi[G_t \mid S_t = s]\)는 기댓값이니까, 상태 \(s\)에서 시작한 리턴 샘플들을 많이 모아 평균 내면 \(v_\pi(s)\)에 가까워진다!

Evaluate Value Function using MC 증분 평균

p.11
\[v_\pi(s) = \E_\pi[G \mid s]\]
\[V_n(s) = \frac{G^{(1)} + G^{(2)} + \cdots + G^{(n)}}{n}\]

매번 전부 다시 더하지 않고 이전 평균만으로 갱신할 수 있어요:

\[\begin{aligned} V_n(s) &= \frac{(n-1)V_{n-1}(s) + G^{(n)}}{n} \\ &= V_{n-1}(s) + \frac{1}{n}\big(G^{(n)} - V_{n-1}(s)\big) \quad \text{: Incremental Monte Carlo updates} \end{aligned}\]
패턴 기억하기새 추정 = 옛 추정 + 스텝크기 × (목표 − 옛 추정). 이 꼴은 TD, SARSA, Q-learning에서도 계속 나와요!

Example: two trials 계산 연습

p.12

같은 상태 \(s\)에서 두 번 시작했을 때 (\(\gamma = 0.9\)):

  • 1st trial: 보상 1, 0, 2 → \(G^{(1)} = 1 + 0.9\cdot 0 + 0.9^2 \cdot 2 = 2.62\)
  • 2nd trial: 보상 0, 0, 1, 1 → \(G^{(2)} = 0 + 0.9\cdot 0 + 0.9^2\cdot 1 + 0.9^3\cdot 1 = 1.54\)
\[V_\pi(s) = \frac{2.62 + 1.54}{2} = 2.08 = 2.62 + \tfrac12(1.54 - 2.62) = 2.62 - 0.54 = 2.08\]

그리고 한 에피소드 안의 모든 상태의 리턴은 뒤에서부터 재귀적으로 효율적으로 구해요:

\[G_A = R_0 + \gamma R_1 + \gamma^2 R_2,\quad G_B = R_1 + \gamma R_2,\quad G_C = R_2\]
\[G_C = R_2,\quad G_B = R_1 + \gamma G_C,\quad G_A = R_0 + \gamma G_B\]

How to Improve? v 대신 q 를!

p.13

DP에서는 \(v\)로 그리디 정책을 만들었어요:

\[\mu(s) = \argmax_a \sum_{s'} p(s'\mid s,a)\{r(s,a,s') + \gamma V(s')\}\]

하지만 MC는 model-free — \(p\)도 \(\Rc\)도 몰라요! 그래서 이 식을 쓸 수 없어요. 대신 Q-함수(행동가치함수)를 평가하면 모델 없이 바로 그리디 정책을 만들 수 있어요:

\[\mu(s) = \argmax_a Q(s,a)\]
\[\begin{aligned} V_n(s) &= \tfrac{G^{(1)} + \cdots + G^{(n)}}{n} \\ &= V_{n-1}(s) + \tfrac{1}{n}\big(G^{(n)} - V_{n-1}(s)\big)\end{aligned}\]
\[\begin{aligned} Q_n(s,a) &= \tfrac{G^{(1)} + \cdots + G^{(n)}}{n} \\ &= Q_{n-1}(s,a) + \tfrac{1}{n}\big(G^{(n)} - Q_{n-1}(s,a)\big)\end{aligned}\]

ε-Greedy Exploration

p.22
  • 지속적인 탐험을 보장하는 가장 단순한 아이디어
  • 모든 \(m\)개 행동이 0이 아닌 확률로 시도된다
  • 확률 \(1-\varepsilon\)으로 그리디 행동 선택
  • 확률 \(\varepsilon\)으로 무작위 행동 선택 (그리디 행동 포함!)
\[\pi(a \mid s) = \begin{cases} \dfrac{\varepsilon}{m} + 1 - \varepsilon & \text{if } a = \argmax_{a^* \in \A} Q(s, a^*) \\[2mm] \dfrac{\varepsilon}{m} & \text{otherwise} \end{cases}\]

ε-Greedy Policy Improvement 정리 + 증명

p.25
theorem

임의의 ε-greedy 정책 \(\pi\)에 대해, \(q_\pi\)에 대한 ε-greedy 정책 \(\pi'\)는 개선이다: \(v_{\pi'}(s) \ge v_\pi(s)\).

proof
\[\begin{aligned} q_\pi(s, \pi'(s)) &= \sum_{a \in \A} \pi'(a\mid s)\, q_\pi(s,a) \\ &= \frac{\varepsilon}{m}\sum_{a \in \A} q_\pi(s,a) + (1-\varepsilon)\max_{a \in \A} q_\pi(s,a) \\ &\ge \frac{\varepsilon}{m}\sum_{a \in \A} q_\pi(s,a) + (1-\varepsilon)\sum_{a \in \A}\frac{\pi(a\mid s) - \frac{\varepsilon}{m}}{1-\varepsilon}\, q_\pi(s,a) \\ &= \sum_{a \in \A} \pi(a\mid s)\, q_\pi(s,a) = v_\pi(s) \end{aligned}\]

부등호: \(\frac{\pi(a\mid s) - \varepsilon/m}{1-\varepsilon}\)는 합이 1인 음이 아닌 가중치(π가 ε-greedy니까 \(\pi(a\mid s) \ge \varepsilon/m\))라서 그 가중평균은 max보다 작거나 같다.

그러면 정책 개선 정리(\(q_\pi(s,\pi'(s)) \ge v_\pi(s)\ \forall s \Rightarrow v_{\pi'}(s) \ge v_\pi(s)\ \forall s\))에 의해 \(v_{\pi'} \ge v_\pi\). \(\blacksquare\)

ε-soft Optimal Policy

p.26
definition

ε-soft 정책: 어떤 \(\varepsilon \gt 0\)에 대해 모든 상태·행동에서 \(\pi(a\mid s) \ge \dfrac{\varepsilon}{|\A(s)|}\)인 정책.

definition

ε-soft 최적 정책:

\[\pi^*_\varepsilon \in \argmax_{\pi \in \Pi_\varepsilon} v_\pi(s),\ \forall s \in \S, \qquad \Pi_\varepsilon = \Big\{\pi \;\Big|\; \pi(a\mid s) \ge \frac{\varepsilon}{|\A(s)|},\ \forall s \in \S, a \in \A(s)\Big\}\]

ε를 상수로 고정하면 MC 정책 이터레이션과 MC 제어 모두 (진짜 최적이 아닌) ε-soft 최적 정책으로 수렴해요. 항상 ε만큼 랜덤하게 행동해야 하니까 그 제약 안에서의 최선.

Greedy in the Limit with Infinite Exploration GLIE

p.27
definition · glie
  • 모든 상태-행동 쌍이 무한히 많이 탐험된다: \(\displaystyle\lim_{k\to\infty} N_k(s,a) = \infty\)
  • 정책이 그리디 정책으로 수렴한다: \(\displaystyle\lim_{k\to\infty} \pi_k(a\mid s) = \mathbf{1}\big(a = \argmax_{a' \in \A} Q_k(s,a')\big)\)

예: \(\varepsilon_k = \dfrac{1}{k}\)로 ε을 0으로 줄여 나가는 ε-greedy는 GLIE.

직관처음엔 많이 탐험하고(모든 걸 충분히 시도), 나중엔 점점 그리디하게(배운 걸 활용). 탐험과 활용의 균형을 시간에 따라 조절!

Convergence of MC RL to Optimal Policy

p.28
theorem

GLIE Monte Carlo control은 최적 행동가치함수로 수렴한다: \(Q(s,a) \to q_*(s,a)\).

  1. \(\pi\)로 \(k\)번째 에피소드 샘플: \(\{S_1, A_1, R_2, \dots, S_T\} \sim \pi\)
  2. 에피소드의 각 \(S_t, A_t\)에 대해
    \[N(S_t,A_t) \leftarrow N(S_t,A_t) + 1, \qquad Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \frac{1}{N(S_t,A_t)}\big(G_t - Q(S_t,A_t)\big)\]
  3. 새 행동가치함수로 정책 개선: \(\varepsilon \leftarrow 1/k\), \(\pi \leftarrow \varepsilon\text{-greedy}(Q)\)

Monte Carlo Reinforcement Learning 요약

p.29 – 32
  • MC는 에피소드 경험으로부터 직접 학습한다.
  • MC는 model-free: MDP의 전이/보상을 몰라도 된다.
  • MC는 완전한 에피소드로부터 학습한다: 부트스트래핑을 하지 않는다.
    • Bootstrapping: 다른 추정치를 바탕으로 추정치를 갱신하는 것
    • 예) VI: \(V_{k+1}(s) = \max_a \sum_{s'} p(s'\mid s,a)\{r + \gamma V_k(s')\}\) — \(V_k\)라는 추정치로 \(V_{k+1}\)을 만듦
  • MC는 가능한 가장 단순한 아이디어를 쓴다: 가치 = 평균 리턴

복습 (2장): 에이전트의 3요소(정책, 가치함수, 모델)와 분류. MC 에이전트는 Model-free, Value-based (Q를 학습하고 ε-greedy로 정책을 암묵적으로 정의).

Monte Carlo Agent McAgent

p.36 – 38 
class McAgent:
    def __init__(self):
        self.gamma = 0.9
        self.epsilon = 0.1
        self.action_size = 4

        random_actions = {0: 0.25, 1: 0.25, 2: 0.25, 3: 0.25}
        self.pi = defaultdict(lambda: random_actions)  # 처음엔 무작위 정책
        self.Q = defaultdict(lambda: 0)
        self.cnts = defaultdict(lambda: 0)              # N(s,a)
        self.memory = []

    def reset(self):
        self.memory.clear()

    def get_action(self, state):
        action_probs = self.pi[state]
        actions = list(action_probs.keys())
        probs = list(action_probs.values())
        return np.random.choice(actions, p=probs)

    def add(self, state, action, reward):
        data = (state, action, reward)
        self.memory.append(data)

    def update(self):
        G = dict()
        g = 0
        for data in reversed(self.memory):     # 뒤에서부터 G 계산
            state, action, reward = data
            g = self.gamma * g + reward
            key = (state, action)
            G[key] = g                          # 덮어쓰기 → 결국 first-visit G 가 남음

        for key, g in G.items():
            state, action = key
            self.cnts[key] += 1
            self.Q[key] += (g - self.Q[key]) / self.cnts[key]      # 증분 평균
            self.pi[state] = greedy_probs(self.Q, state, self.epsilon)  # 개선

ε-greedy policy greedy_probs

p.39 
def greedy_probs(Q, state, epsilon=0, action_size=4):
    qs = [Q[(state, action)] for action in range(action_size)]
    max_q = np.max(qs)
    max_actions = [a for a, q in enumerate(qs) if q == max_q]
    max_action = np.random.choice(max_actions)   # tie-breaking
    base_prob = epsilon / action_size             # ε/m
    action_probs = {action: base_prob for action in range(action_size)}
    action_probs[max_action] += (1 - epsilon)     # 그리디 행동엔 1−ε 추가
    return action_probs

Q 값이 같은 행동이 여러 개면 무작위로 하나 골라 그리디 행동으로 삼아요 (tie-breaking). 처음엔 모든 Q가 0이니까 특히 중요!

Non-Stationary Problem 비정상 문제

p.40 – 42

큰 수의 법칙은 표본이 i.i.d.일 때 성립해요. 그런데 \(G^{(n)}\)들이 동일한 분포에서 나올까요?

아니요. 정책 \(\pi(a\mid s)\)가 계속 바뀌니까 리턴의 분포도 계속 바뀌어요 → 비정상(non-stationary).

해결: 표본평균 대신 지수이동평균(exponential moving average)을 사용:

\[Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \frac{1}{N(S_t,A_t)}\big(G_t - Q(S_t,A_t)\big) \quad\Longrightarrow\quad Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \alpha\big(G_t - Q(S_t,A_t)\big)\]

왜 “지수” 이동평균?

\[\begin{aligned} Q_n(s,a) &= \alpha G^{(n)} + (1-\alpha) Q_{n-1}(s,a) \\ &= \alpha G^{(n)} + (1-\alpha)\big[\alpha G^{(n-1)} + (1-\alpha) Q_{n-2}(s,a)\big] \\ &= \alpha G^{(n)} + \alpha(1-\alpha) G^{(n-1)} + (1-\alpha)^2 Q_{n-2}(s,a) \\ &= \alpha G^{(n)} + \alpha(1-\alpha) G^{(n-1)} + \alpha(1-\alpha)^2 G^{(n-2)} + \cdots + \alpha(1-\alpha)^{n-1} G^{(1)} + (1-\alpha)^n Q_0(s,a) \end{aligned}\]

가중치의 합: \(\sum_{i=1}^{n} \alpha(1-\alpha)^{n-i} + (1-\alpha)^n = 1\). 오래된 리턴일수록 가중치가 지수적으로 작아져요 → 최근 데이터를 더 믿음!

Self-check 스스로 확인하기

MC에서 V 대신 Q를 추정하는 이유는?
V로 그리디 정책을 만들려면 \(p(s'\mid s,a)\)와 \(r\)이 필요한데 MC는 model-free라 모름. Q가 있으면 \(\argmax_a Q(s,a)\)로 모델 없이 바로 정책을 만들 수 있음.
ε=0.2, 행동 4개일 때 그리디 행동과 나머지 행동의 확률은?
그리디: \(0.2/4 + 0.8 = 0.85\), 나머지: \(0.05\) 씩.
First-visit MC와 Every-visit MC의 차이는?
한 에피소드에서 같은 (s,a)를 여러 번 방문할 때, first-visit은 처음 방문 시점의 리턴만, every-visit은 모든 방문 시점의 리턴을 평균에 사용.
GLIE의 두 조건은?
(1) 모든 (s,a)를 무한히 방문, (2) 정책이 그리디 정책으로 수렴. 예: \(\varepsilon_k = 1/k\).
상수 ε로 MC 제어를 돌리면 어디로 수렴하나요?
진짜 최적 정책이 아니라 ε-soft 최적 정책.
MC 업데이트에서 1/N 대신 α를 쓰는 이유는?
정책이 계속 바뀌어 리턴이 i.i.d.가 아님(비정상). α를 쓰면 지수이동평균이 되어 최근 리턴에 더 큰 가중치를 줌.
“부트스트래핑”이란? MC는 하나요?
다른 추정치를 바탕으로 추정치를 갱신하는 것 (예: DP의 \(V_k\)로 \(V_{k+1}\) 계산). MC는 실제 리턴 \(G_t\)만 쓰므로 부트스트래핑을 하지 않음.
