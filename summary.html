02 · Finite MDP

“강화학습 문제 = MDP 라는 틀에 담는다”

  • 마르코프 성질: 미래는 현재 상태만으로 결정 (과거 불필요)
  • MP \(\langle\S,\P\rangle\) → MRP \(+\Rc,\gamma\) → MDP \(+\A\) (전이·보상이 행동에 의존)
  • 리턴 \(G_t\) = 할인된 미래 보상의 합. γ 작으면 근시안, 크면 원시안
  • 정책 π(a|s), 가치함수 v_π(s), q_π(s,a), 모델 (P, R) = 에이전트의 3요소
  • 최적 정책 정리: 모든 상태에서 최고인 π* 가 항상 존재하고 v*, q* 를 달성

꼭 외울 식

\[G_t = \sum_{k=0}^{\infty}\gamma^k R_{t+k+1} = R_{t+1} + \gamma G_{t+1}\]
\[v_\pi(s) = \E_\pi[G_t\mid S_t=s],\quad v_\pi(s) = \sum_a \pi(a\mid s)\,q_\pi(s,a)\]
\[v_*(s) = \max_\pi v_\pi(s),\quad q_*(s,a) = \max_\pi q_\pi(s,a)\]

자주 헷갈림

  • Continuous task 는 \(\gamma \ne 1\) (리턴 발산 방지)
  • 정책 순서는 부분 순서 — 모든 정책 쌍이 비교 가능한 건 아님
  • 사과 예제 Policy 2 (L,R) 의 v(0) = −10: 상태 1에 절대 못 감
  • \(r(s,a) = \sum_{s'} p(s'\mid s,a)\,r\) — 기대 보상 (택시: r(Airport,Wait)=4.3)

03 · Bellman Equation

“지금 가치 = 바로 받는 보상 + γ × 다음 가치”

  • 기대 방정식: 정책 π 의 가치를 재귀적으로 표현 (π로 평균)
  • 최적 방정식: 평균 대신 max → 비선형이라 역행렬로 못 풂
  • 유도 4단계 근거: 전기댓값 법칙 → 연쇄법칙 → 마르코프 성질 → 가치함수 정의
  • 행렬형 \(v_\pi = (I-\gamma\P^\pi)^{-1}\Rc^\pi\) — \(O(n^3)\) 이라 큰 문제엔 비현실적
  • 벨만 최적 연산자 T 는 \(\|\cdot\|_\infty\) 에서 γ-축약사상 → 바나흐 고정점 정리 → v* 가 존재·유일, 반복하면 수렴

꼭 외울 식

\[v_\pi(s) = \sum_a\sum_{s'}\pi(a\mid s)p(s'\mid s,a)[r + \gamma v_\pi(s')]\]
\[q_\pi(s,a) = \sum_{s'}p(s'\mid s,a)\Big[r + \gamma\sum_{a'}\pi(a'\mid s')q_\pi(s',a')\Big]\]
\[v_*(s) = \max_a\sum_{s'}p(s'\mid s,a)[r + \gamma v_*(s')]\]
\[q_*(s,a) = \sum_{s'}p(s'\mid s,a)[r + \gamma \max_{a'}q_*(s',a')]\]

자주 헷갈림

  • q 의 기대 방정식은 첫 행동이 이미 정해져 있어 π 는 다음 상태에서만 등장
  • \(v_*(s) = \max_a q_*(s,a)\) 는 “더 좋은 행동이 있으면 바꿔서 개선 가능”하다는 정리에서 나옴
  • 축약 증명에서 보상 R 은 빼면 상쇄, max 차이는 보조정리 \(|\max f_1 - \max f_2| \le \max|f_1-f_2|\)
  • 바나흐 정리 조건: 완비 거리공간 + 축약사상 (ℚ 는 완비 아님)

04 · Dynamic Programming

“모델을 알면 벨만 방정식을 반복 적용해서 정확히 푼다”

  • DP 3성질: 부분구조 · 테이블 · 상향식 (\(V_0=0 \to V_1 \to V_2 \cdots\))
  • 정책 평가: 벨만 기대 백업 반복 → \(v_\pi\) (기대 연산자도 γ-축약)
  • 정책 이터레이션: 평가(끝까지) ↔ 그리디 개선. 정책 수가 유한 → 유한 번에 π*
  • 정책 개선 정리: \(q_\pi(s,\pi'(s)) \ge v_\pi(s)\ \forall s \Rightarrow v_{\pi'} \ge v_\pi\)
  • 가치 이터레이션: 개선+평가를 max 하나로. 명시적 정책 없음
  • GPI: 어떤 평가 + 어떤 개선이든 번갈아 하면 OK (MC 제어·SARSA 도 GPI)
  • 비동기 DP: In-place(표 1개), Prioritized sweeping(벨만 오차 큰 상태 먼저)

꼭 외울 식

\[\text{PE: } V_{k+1}(s) = \sum_a\pi(a\mid s)\sum_{s'}p\,[r + \gamma V_k(s')]\]
\[\text{개선: } \pi'(s) = \argmax_a \sum_{s'}p\,[r + \gamma v_\pi(s')]\]
\[\text{VI: } V_{k+1}(s) = \max_a\sum_{s'}p\,[r + \gamma V_k(s')]\]

FrozenLake: 무작위 정책 v(0)≈0.04, 최적 v*(0)=10×0.9⁵≈5.9

자주 헷갈림

  • PE 는 주어진 정책 평가, VI 는 최적 가치 찾기
  • PI 는 평가를 수렴까지, VI 는 사실상 평가 1번 + 개선을 합친 것
  • 가치가 완전히 수렴하기 전에도 그리디 정책은 이미 최적일 수 있음 (k=5 vs ∞)
  • 비동기 DP 수렴 조건: 모든 상태가 계속 선택될 것

05 · Monte Carlo

“끝까지 해 보고, 받은 리턴을 평균 낸다”

  • Model-free, 완전한 에피소드에서 학습, 부트스트래핑 X, 가치 = 평균 리턴 (큰 수의 법칙)
  • 모델이 없으니 V 대신 Q 를 학습해야 \(\argmax_a Q\) 로 정책 개선 가능
  • 리턴은 에피소드 뒤에서부터: \(g \leftarrow r + \gamma g\). First-visit: 처음 방문 시 G 만 사용
  • 순수 그리디는 첫 경로에 갇힘 → ε-greedy 탐험 (ε-greedy 개선도 정책 개선 정리 만족)
  • ε 고정 → ε-soft 최적으로 수렴. GLIE (예: ε=1/k) 면 q* 로 수렴
  • 정책이 변해 리턴이 i.i.d. 아님(비정상) → 1/N 대신 α (지수이동평균)

꼭 외울 식

\[Q(S_t,A_t) \leftarrow Q + \tfrac{1}{N(S_t,A_t)}\big(G_t - Q\big)\ \text{ or }\ Q + \alpha(G_t - Q)\]
\[\pi(a\mid s) = \begin{cases}\varepsilon/m + 1-\varepsilon & a = \argmax Q \\ \varepsilon/m & \text{otherwise}\end{cases}\]
\[\text{GLIE: } N_k(s,a)\to\infty,\quad \pi_k \to \text{greedy}\]

자주 헷갈림

  • ε-greedy 에서 그리디 행동 확률은 \(1-\varepsilon\) 이 아니라 \(1-\varepsilon+\varepsilon/m\)
  • MC Policy Iteration(수렴 후 개선) vs MC Control(매 에피소드 개선)
  • 구현 코드: reversed + dict 덮어쓰기 = first-visit
  • MC 는 continuous task 에 못 씀 (에피소드가 안 끝나서)

06 · Temporal Difference

“한 스텝만 가 보고, 다음 상태의 추정치로 바로 고친다”

  • TD = MC 의 샘플링 + DP 의 부트스트래핑. 매 스텝 온라인, continuous task OK
  • TD 타깃은 편향 있지만 분산 작음, MC 리턴은 편향 0, 분산 큼
  • Batch: MC 는 관측 리턴에 맞춤, TD 는 추정 MDP 에 맞춤 (AB 예제: V(A) 0 vs 0.75) → TD 는 마르코프 성질 활용
  • SARSA(기대 방정식 샘플, on-policy) vs Q-learning(최적 방정식 샘플, off-policy)
  • 수렴 조건: GLIE + Robbins-Monro (\(\sum\alpha = \infty, \sum\alpha^2 \lt \infty\))
  • Cliff: Q-learning = 절벽 옆 최단(위험), SARSA = 멀리 안전한 길
  • n-step, λ-return(TD(0)=TD, TD(1)=MC), backward view = eligibility trace

꼭 외울 식

\[\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t),\quad V(S_t) \leftarrow V(S_t) + \alpha\delta_t\]
\[\text{SARSA: } Q(S,A) \mathrel{+}= \alpha[R + \gamma Q(S',A') - Q(S,A)]\]
\[\text{Q-learning: } Q(S,A) \mathrel{+}= \alpha[R + \gamma\max_a Q(S',a) - Q(S,A)]\]
\[E_t(s) = \gamma\lambda E_{t-1}(s) + \mathbf{1}(S_t=s),\quad V(s) \mathrel{+}= \alpha\delta_t E_t(s)\]

자주 헷갈림

  • Q-learning 도 행동은 ε-greedy 로 함 — 타깃만 max (target ≠ behavior)
  • Cliff 에서 학습 중 평균 보상은 오히려 SARSA 가 높음
  • On-policy: 안정적·샘플 비효율 / Off-policy: 불안정·샘플 효율
  • λ-return 가중치 \((1-\lambda)\lambda^{n-1}\), 남는 꼬리는 실제 리턴에
  • Watkins Q(λ): 탐험 행동(A′≠A*) 하면 trace 를 0 으로 끊음
